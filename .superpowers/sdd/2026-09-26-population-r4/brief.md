# 设计要点：R4（人口第一次动起来 + 让纺织持续）

> **给实现者**：本文只给**判断与判据**，代码你写、测试你跑。
> 判据出处：`docs/superpowers/specs/2026-09-26-population-economy-v3-design.md` 的 **§七（人口再生产与危机）**、§四、§六、§九 R4 行、§十。
> 前序：R1（`69487db`）/ R1.5（`dcffa45`）/ R2（`b40a353`）/ R3（`7abaea2`）已关账；要点在 `.superpowers/sdd/2026-09-26-population-r{1,15,2,3}/brief.md`（**先读**）。

## 目标（一句话）

**让"人"第一次真的随时间变**（年龄推进 + 月度出生 + 死亡 + 生理压力），并**让 R3 的纺织不再第 2 周期停工**。

## 范围

### T0：跨行实物转移（**R3 的遗留，必须收口**）

R3 报告原文：织机与作坊吃的原料是**创世一次性给的**（= 本格农田一个周期的纤维副产），
把田里的纤维**搬到**织机上属跨行实物转移 ⇒ **第 2 周期起停工**，而农田自己产的纤维照常累积（一年后 71.2 亿毫）。

⇒ **本轮让它持续**。最小形态（**不要**做成完整的市场/清算）：

- **同格**内、**单向**、**按需**的实物转移：织机缺 `FIBER` ⇒ 从**同格**有富余的行取（取多少 = 缺多少，上限 = 供方的富余）。
- ★ **必须对称记账**：供方减库存（**并记进它的 `consumed`**，否则守恒式不成立——R2 与 V3 都栽过"单侧扣减"）、
  受方加库存；两侧都在**同一份变更集**里（同格同切片，天然原子）。
- ★ **拒"凭空造"**：取不到就**停工**（记缺口或按"投入不足 ⇒ 规模缩"处理，与 `scaleOf` 的既有口径一致）。
- ★ **本轮不做**：跨格转移、运输、价格、市场撮合、货币 —— 那些是 V8/市场轮的事。

### T1：年龄推进 + 月度出生 + 死亡 + 生理压力

- **年龄推进**：`PopulationGroup` 的年龄是**派生纯函数**（`ageAtAnchorDays + (nowTick - anchorTick)`）
  ⇒ **不需要改字段**。本轮要做的是**让 `social` 的参与者真的算它**（R1 的参与者交的是**不变变更集**）。
  ★ 判据：推 365 天后，某批次的 `ageDaysAt` 比推进前**大 365**（**不是**改 `ageAtAnchorDays`）。
- **出生：月度结算**（每 30 天一次）。育龄女性按**具体年龄、人数、历史生活资料满足情况**产生出生。
  ★ **第一版不做复杂家庭婚姻机制**（spec 原文），但**至少不要用总人口乘一个增长率**。
  ★ 参数（育龄区间、每周期生育率、生活资料对生育的修正）**具名常量 + 注释"V7 参数目录落地后迁入"**，**不造目录**。
- **死亡**：`年龄 × 性别 × 基础死亡率 × 生理压力`。
  ★★ **缺粮不直接对应死亡人数**，而是累积 `physiologicalStress`：
  **短期缺粮加一些、恢复供给后逐渐消退，长期严重不足才显著抬高死亡率**。
  **判据（spec §九 R4 行原文）：缺粮"五天"与"半年"产生不同的死亡结果。** 这条必须有逐值用例。
- ★ **人口守恒**：出生/死亡都要**显式落账**（`FlowRow` 已有 `deaths`；出生需要一个对称项）。
  ★ **饿死路径与配额的旧账一起收口**：R2 记过"`applyFamine` 缩的是**行**劳动，而当日劳动取自**配额**"⇒
  本轮人口真的会变，**这条必须补齐**（否则"人死了劳动没减"）。

### T2：布的消费（让 R3 的布**有用**）

- R3 已把布写进 `naturalNeeds`（形状），但**不消费、不进饿死判据**。
- 本轮：**布真的被消费**（每人每 365 天 1 匹，R3 已定的口径），缺口进 `unmetNeed` 的**同一套**记账。
- ★★ **但"粮食不足与衣物不足对死亡的时间尺度显然不能一样"**（spec §七）⇒
  布缺对 `physiologicalStress` 的贡献**必须与粮缺分开表达**（各自的系数），**不许合并成一个数**。

### T3：`CrisisMonitor`（薄）

- 按"当前需求满足水平 / 相比历史基线的突变 / 儿童·青壮年·老年人分别受影响程度 / 债务增长 / 劳动负担"，
  向 GM 出**红灯**。
- ★★ **它输出的是"某地发生生活资料/社会再生产危机"，不是"暴动概率 83%"**。
- ★ **本阶段绝不生成起义机制**（spec §七 原文）——起义/逃亡/抢粮/请愿/救济留给以后的政治系统。
- ★ 读口暴露；**沿用既有权限判定**，不许另造更宽的。

## 不做（留白，不是遗漏）

1. **V8 完整统一转移**（`ResourceRequest → EconomicTransfer` 的通用原语）：T0 只做**同格单向、按需**的最小形态；
   完整的（含市场/信用/跨格）归下一轮。
2. **庄园制度**（`LABOR_RENT`/`IN_KIND_RENT`/`MONEY_RENT`）归下一轮。
3. **市场 / 价格 / 货币**；**参数目录**；**`simos-ledger`**（一行不动）。
4. **季节性**（农忙/农闲调纺织配额）：R3 已把配额做成可按天变，但季节曲线归下一轮。

## 铁律

- **不许放宽断言**；合法改法只有"按新口径重算期望值"（算式写进注释）与"修夹具"。
- ★★ **真档数字这次会大变**（人口开始变、布开始被消费、纺织持续）⇒ **必须手算重算端到端字面量**，**不许抄实际值**；
  对不上先核算式、先查被测物，并报告差异。
- ★★ **夹具必须刻意混合**：本轮做"转移/出生/死亡/压力"，夹具里**必须真的有**：
  ① 一个**供方富余、受方不足**的同格对；② 一个**育龄女性批次**；③ 一个**长期缺粮**与一个**短期缺粮**的对照。
  否则"不转移/不生育/不看压力"的实现照样绿（**假绿**）。**R1/R1.5/R2/R3 的实现者各栽过一次，四次都是自查出来的。**
- **判别力声明必须真的成立**：写完"由 X 承担判别力"，X 必须**存在**且**真的会红**；**逐条自检并把表报给我**。
- **每条护栏配变异自证**：改坏 ⇒ 必须**红** ⇒ **Edit 反向重写**还原（比 md5）⇒ 复绿。
- ★ **机械改动逐个 Edit，不要用批量脚本**。
- ★ **测试一律一次一个类**（R2 踩到过多类 `-Dtest` 过滤的假绿）；**最终判据一律整轮 `clean verify`**。
- ★ **验证工具本身**：报"零命中/全绿"前先证明读取模式对。**禁止 `2>/dev/null` 吞工具错误**。
- **一次只能跑一个 Maven**；判过不过看 `target/surefire-reports/*.txt` 的 **mtime 落在本轮**，不看 rc。
- 改完跑 `./mvnw -q spotless:apply`；若它动了你没改过的文件，**停下报告**。
- **收尾前台跑 `./mvnw clean verify`**，把 **Reactor 逐模块结果**抄进报告。
- **不要 `git commit`**。

## ★ 本轮的"真档可见性"判据（必须给数字）

推**一年**（真档 138 格奥斯特马克，走真 MCP 播种）后，报告里必须能读到：

1. **人口变化**：出生数、死亡数、年末人口（与创世人口之差**有解释**：出生 − 死亡）
2. **年龄结构演化**：三个年龄档的人数**与创世不同**（年龄推进的可见后果）
3. **纺织持续**：`CLOTH` 库存在**每个周期**都增长（不是只有第 1 个周期）
4. **布的消费**：`CLOTH` 的 `consumed` 非零
5. **危机红灯**：若有格触发，给出**类别**（不是概率）
