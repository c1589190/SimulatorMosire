## 打算怎么做（待用户确认/修正）

1. **起实例**（守 AGENT.md §二「产物」与 §8.1）：
   - 先确认无 Maven/服务在跑；**停掉已有实例再打包**（运行中被就地重写的 jar 会 `ClassNotFoundException`）
   - `./mvnw -DskipTests package -pl simos-app -am`
   - `tools/run-shaded.sh <shaded.jar> --store /tmp/simos-store-year1 --gui-port 5817`（**用别的端口，别动已有的进程**）
2. **种子世界**：空库首启只种**地图 + 区域**（`cities:0`、`units:[]` **不是故障**）；
   人口/城市/军队/经济要靠 GM MCP 工具 **`simos.worldgen.initialize`**（三国各一次，输入 `config/worldgen/v17levant-nations.json`）
3. **推进 365 天**：`cycleDays = 120` ⇒ 一年 = **3 个完整周期 + 5 天**（第 120/240/360 天各收获一次）。
   ★ 推进语义是"一次 N 天、内部逐日"，但**逐日推 365 次更便于取中间读数**（日/周期曲线）——按报表需要定。
4. **读数**：读口是**逐格**的（`/api/economy/hex?q=&r=`，GUI 与 MCP 同一份视图）⇒ 799 格要**脚本循环**取再聚合。
   所有 curl 都要 `--noproxy '*'`（本机代理会拦 127.0.0.1）。
5. **判活**：`/`、`/index.html`、`/styles.css` 三条都 200（只看 `/api/*` 会漏判"jar 被就地重写"）+ 进程在。
6. **收工用 PID**（`ps -eo pid,cmd | grep simos-shaded` ⇒ `kill <pid>`），**别 `pkill -f`**（会连执行它的 shell 一起杀，已踩 4 次）。

## 报表计划包含（先列出来，用户可增删）

- **总量**：三国各自的 人口 / 口粮库存 / 货币 / 土地 / 债务本金 / 未满足需求（缺口）
- **分层**：四阶层（贫农/中农/富农/地主）各自的人口、库存、债务、参与率
- **周期曲线**：第 120/240/360 天收获前后的库存与所得（"青黄不接 → 收获"是否可见）
- **制度**：各产业制度、分配权重、生产周期进度
- **守恒**：推进前后粮/钱/人口总量（含税/损耗/债务的显式落账项）

## ★ 两条**已知**会决定报表长相的事实（来自代码，非预测）

1. **手工业恒产 0**：`EconomySeeder` 给手工业的 `meansOfProduction` 是空（无 LAND），
   而 `harvest` 的产出按 `LAND` 亩数算 ⇒ **城市格的 12~13% 人口是纯消费者**，只会借粮、不会产粮。
   ⇒ 报表预期会显示：城市格债务持续累积、靠农业行放贷活着。**这是建模缺口，不是模拟故障。**
2. **致死率默认 0‰**（V4 落地）：缺口**只记数、不杀人**。⇒ 一年后人口**应当不变**（除播种/收获无人口动因）。
   ⇒ 报表里人口若变了，那是 bug，要查。
