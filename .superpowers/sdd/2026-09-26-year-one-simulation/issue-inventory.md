# v3 模拟：问题清单 v2（考察后重写）

**v1 的问题**（外部审查 2026-09-26 指出，已采纳）：把**现象**当成了分类对象，导致 F 与 M 天然重叠；
"反向判据"写得过绝；因果强度超出证据；市场与货币的依赖顺序写反了。
**v2 的改动**：F 退出分类，改为**证据层**；补三项考察证据（含一次**判决性 counterfactual 实验**）；
重排依赖顺序；U2 改名。

---

## 〇、判定框架（v2）

**分类只给「机制节点」定性，不给「现象」定性** —— 这是 v1 的病根。

| 类 | 定义 | 处置 |
|---|---|---|
| **B｜机制错** | 机制**已存在**，但算错/漏算 | **必须独立修**（与交换体系正交） |
| **M｜机制缺** | 该有的机制**还没做** | **不要打补丁**（会在机制落地时返工，且掩盖真问题） |
| **U｜机制未决** | 机制**部分存在**，但**没人明确说另半边做不做** | **需裁定**，否则永远是缺口 |

**F 不是第四类**：F = **观测事实 / 证据**。它**不参与互斥**，一条 F 可以**同时支撑**多条 B/M/U 的判定。
（v1 把"城市地少"既列为 M2 又列为 F2，看着像自相矛盾 —— 其实前者是机制判定、后者是证据，**层次不同**。）

**反向判据（弱化版，v1 写得过绝）**：
~~"贸易后产区不外流粮食 ⇒ bug"~~ ⇒
**"在计入运输成本、运力、损耗、最低库存、赊销限制与支付能力之后，仍存在可执行的正套利，而系统长期不成交，
才怀疑市场/路由 bug。"** 不成交完全可能是上述任一约束的正常结果。

## 二、机制问题定性

### B｜机制错（2 条，均已补足证据）

**B1. `applyDailyStress` 漏掉无配额批次**（证据 F7）
`PopulationEconomyTimeParticipant.java:186-189` 用 `industriesOf`（源自 `economy.allocations()`）过滤批次；
没有配额的批次直接 `continue` ⇒ 压力永不更新。两类批次从未有过配额：**0-14 档**（劳动系数 0）、
**全部新生儿批次**（创世后产生）。

★ **考察补足的最后一锤**：`new LaborAllocation` 在 main 源码里只出现于
`EconomySettlement.java:672/707`（`scaleLaborOfIndustry` / `scaleLaborOfGroup` —— **缩放既有配额**）
与 `EconomyPayloads.java:208`（读档解析）；**创建点只有 `EconomySeeder.appendAllocation`（创世）**。
⇒ **没有任何"年龄跨档时重建 allocation"的逻辑** ⇒ 新生儿**永远**拿不到配额。
（v1 的"15 年后进入育龄仍无配额"当时是推断，**现在有代码证据**。）

★ **后果表述更正**（v1 写重了）：不是"儿童在饥荒中不死"，而是
**"儿童不承受压力导致的超额死亡"** —— `mortalityPerMille` 的基础死亡率那一项照常生效（0-14 档 2‰/月）。
真正的严重处是后半句：**饥荒的生育抑制只对创世那一代生效**，随时间自我失效。

**B2. `CrisisMonitor` 相位敏感**（证据 F16）
分子 = 本周期累计 `unmetNeed`；分母 = `cumulativeRationMilli(pop, cycleDays)`（**整周期**）。
两者时间基准不同 ⇒ 周期初满足率虚高 ⇒ 红灯不亮。

★ **考察补足的语义前提**（v1 这里还带一点 U 的成分）：v3 spec §七 原文是
"按**当前**需求满足水平……向 GM 出**红灯**"，且该读口挂在 `/api/social/population` 这个**实时**端点上，
javadoc 也写"当场量到的数字"。⇒ **设计语义就是实时指标** ⇒ **是 B，不是 U**。

### M｜机制缺（4 条；**不要打补丁**）

**M1. ★★ 核心：R3/R4 引入了分工，但没有引入交换。**
| 行 | 产出 | 需求 | 结果（证据） |
|---|---|---|---|
| `farm` | 粮 + 纤维 | 粮 + **布** | 缺布（F2） |
| `weave` | 布 | 无（人口 0） | 堆积 62.1B 毫（F4） |
| `craft` | 布 + 工具 | **粮** + 布 | 缺粮（F3） |

三行**本来正好互补**。而行间转移通道只有两条：**同格借粮**（粮专用、债务型）与
**同格取材 `transferIntraHexInputs`**（**仅生产投入、仅周期第一天**）。
⇒ **消费品之间零通道**。

★ **用词更正**（v1 自相矛盾）：F13 应写成"**唯一用于最终消费满足的**跨产业行通道" ——
T0 是生产投入转移，**不服务消费**。

★ **为什么补丁是错的**：给布一条免费通道会产生"没有价格、没有支付能力"的分配，
把 **"买不起"** 这个真实机制（spec §6.1"市场有粮仍可能有人饿"）**永久掩盖**。
分工的收益要靠交换拿，**不能靠搬运**。

**M2. 格间无调配**（证据 F9/F10/F11）：产能 139.8% 但分布不均；68 格结构性缺地；无运输、无在途、无损耗。

**M3. 无价格、无货币。** 当前货币恒 0。

**M4. 无运输/在途基础设施。** 地图有 `pathwayGroups`，经济侧无路线概念。

### U｜机制未决（2 条，需裁定）

**U1. 布该不该有"非市场"通道？**
R4 明确写了"**粮**不走 T0 取材通道"（有意的，理由：粮已有借粮制度），但**布从未被提及**：
它不是生产投入（拿不到 T0），也不是粮（拿不到借贷）⇒ **无人认领的缺口**。
**必须明说**：等市场（M），还是现在给临时通道（会返工）。

**U2. ★ 改名：「生产设施、劳动者与产出所有权的映射」**
（v1 叫"`weave` 行人口是否为 0"，**抓错了层次** —— 那只是表现。）
真正的前置问题是：**62M 布是谁的？收入归谁？谁拿收入去买粮？**
即使明天给 `weave` 塞 10 万人，也**不自动回答**这三个问题。
⇒ 这是**市场的前置设计**，不解决就没法定"谁有资格出售"。

## 三、★ 判决性实验：`布不缺` 的 counterfactual

**为什么要做**：v1 说"人口 −21% 实际由缺布导致"，审查指出这是**把主嫌疑写成已定罪**（死亡还含基础死亡、早期粮缺、压力历史）。
**做法**：单变量改动 —— `PopulationDynamics.stressAfter` 里把布满足率强制为 1000‰
（等价于"布永远满足"：`add` 的布项归零、`decay` 的 `min` 退化为粮满足）。**实验后已 `git checkout` 还原并核验**。

| 指标（600 天末） | 基线（布满足 0%） | **实验（布不缺）** |
|---|---|---|
| **人口** | 9,317,048（**−21.2%**） | **11,698,352（−1.1%）** |
| **末周期出生** | 1,677 | **217,927**（×130） |
| 末周期死亡 | 626,566 | 225,021（−64%） |
| **rural 育龄能生育** | **0 / 799** | **799 / 799** |
| rural 压力中位 | 1,345 | **0** |
| urban 育龄能生育 | 58 / 201 | 42 / 197 |
| 粮库存 | 289.3B 毫 | 259.7B 毫 |
| **新生儿批次压力** | 0 | **0**（B1 独立复现） |

**⇒ 结论（现在可以说强）**：**"布满足率为 0" 是那 21% 人口损失的主导原因** ——
单变量改掉它，人口损失从 −21.2% 收到 **−1.1%**。
★ 而**新生儿压力在两版里都是 0** ⇒ **B1 与 M1 是两个独立缺陷**，被干净分离。

★ **仍未证明的**：−1.1% 那部分（以及两版都有的基础死亡）归因于什么。**未做**那一步的分解。

## 四、依赖顺序（v1 写反了）

v1：「③ U1/U2 → ④ 市场 spec → ⑤ 货币与价格」——**循环依赖**：市场最小实现要先回答"谁卖、谁买、买不起怎么办"，
而这三者在当前模型里**都没有对应物**（无产权、无货币、无信用）。

**修正后的顺序**：

```
① 产出归属 / 经营主体      ← U2（谁的布、谁的收入）
② 结算单位与初始购买力 / 信用  ← 货币与信用至少要有抽象接口（不必是完整货币）
③ 同 Hex 市场 + 价格        ← 价格形成与市场可同阶段设计
④ 跨 Hex 运输与市场         ← Shipment / 在途 / 损耗
```

★ **B 类与这条链完全正交** ⇒ ①之前的任何时刻都可以先修 B1/B2。
