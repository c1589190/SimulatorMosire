## 三、局部规则

1. 本目录新增文档前先判断：是项目设计（去 `../superpowers/`）还是项目维护（本目录）。
2. 当前状态只写 `STATUS.md`；不得在本目录新增“最新状态/唯一入口”文件。
3. 旧长文不删除、不重写正文；需要更正时在文件头加状态/取代头，并在本表登记。
4. 任何旧长文的数字/机制描述在使用前回代码或回当前门禁核；不得拿旧数字当现状。
5. 长文用相对 Markdown 链接，不用 `@` 导入。
