# 工作流维护手册

> **本文件属于项目维护。** 旧的 `02-一-并发.md`、`05-四-台账与代码核对.md`、`06-五-提交与协作.md`
> 保留为历史长文与事故细节；当前操作以本文件 + `MAINTENANCE_RULINGS.md` 为准。
> 项目设计流程（目标运行序列、子设计嵌入、验收判据）仍必须按设计文档执行。

## 一、控制方、子 Agent 与责任区

- **控制方**：调查综合、约束设计、派单、审阅、验收、提交；默认不亲自写生产代码。
- **调查 Agent**：只读；任务书必须给方向与问题清单，禁止无方向扫全项目。
- **办事 Agent**：一个责任区一个写代码 Agent；只写生产代码到编译通过，不写/不改测试，不跑 `test/verify/package`，不 commit。
- **测试 Agent**：全部生产代码落地后统一写测试；按验收判据而不是按代码反推；必须含负向用例，关键项做变异自证。
- **责任区**：一个完整、可编译、可独立验收的目标/问题域；不是计划编号、不是文件数、不是 Task 3.2。
- 同一时刻只允许一个写代码 Agent；只读调查可以并行，但不得共享写目标。
- worktree 一律放 `<仓库根>/worktree/<name>/`；不用 `.claude/worktrees/` 作为新树目录。详见 `ENVIRONMENT.md`。

## 二、派单前必须有的文档

凡是涉及以下任一项，必须先落设计文档，再派实现：
- 持久状态组件、运行时阶段、结算器、时间参与者；
- 对外 API、工具面、载荷、事件、ChangeSet/Codec；
- 数据流/所有权/生命周期、数值公式或硬编码标定。

设计文档至少写：
1. 需求来源与用户原话；
2. 目标/非目标；
3. 现状事实（`file:line`）；
4. 接口、载荷、数据流与所有权；
5. 不变量与失败语义；
6. 验收判据 + 负向用例；
7. 文件所有权与停止条件。

**目标运行设计先行**：先写“目标世界里代码实际怎么跑”（阶段、顺序、读写、数据所有权、失败、日志、测试锚点），再写裁定与子设计嵌入。
详细规则见 `15-十四-目标运行设计与子设计嵌入.md` 与 `.agents/skills/target-runtime-design/SKILL.md`。

**派单书自包含**：引用设计路径 + 小节号，并原样复述关键形状；不能只给链接。子 Agent 若认为设计与用户原话/红线冲突，必须立即上报，控制方转问用户。

## 三、测试与验收节奏

- 用户 2026-09-27 裁定：阶段门禁只做编译，测试统一留到最后。
- 写代码 Agent：`tools/mvn-lock.sh -DskipTests compile`/等价命令到编译通过即可；编译通过不是验收。
- 测试 Agent：统一写测试、跑门禁、做关键项变异自证；报告必须写“没做/没验证/blocker”。
- 多 tick 世界模拟不进 JUnit（用户 2026-10-15 裁定）；见 `VERIFICATION.md`。
- 真实世界长跑测试不进程序化门禁（用户 2026-10-23 裁定）；行为验证走真实 world + 日志。

## 四、评审与停止条件

- 评审按风险触发：权限/判定、进程线程生命周期、共享件、结构性变更才派独立评审。
- 单模块评审不超过 3 轮；代码量小时控制方读 diff 即评审，不为评审自建重型装置。
- 做不到验收判据 = **BLOCKED，不是 DONE**；“写进风险文档/未完成项”不能替代验收判据通过。
- 纯实现困难：给 fail-closed 方案并实现，任务保持 BLOCKED；只有设计冲突/需用户裁定才停手等指令。
- 发现既有文档/台账与代码不一致：先回代码核，按“文档错、实现错还是夹具错”判定；不要照措辞硬做。

## 五、开发中期文档动作

每完成一个责任区、门禁、交接或上下文压缩前：
1. 更新 `STATUS.md`（目标、HEAD、dirty、门禁、未验证、下一步）；
2. 需要长文时写 `docs/superpowers/status/YYYY-MM-DD-*.md`，文件头标历史快照；
3. 新决策按设计/维护分账：设计进 spec，维护进 `MAINTENANCE_RULINGS.md`；
4. 发现可复用判断流程才登记 Skill 候选；
5. 不再把聊天当作唯一留痕。

## 六、提交与协作

- 不 `git add -A`；按关注点分批，提交前看 `git status` 与 `git diff --cached`。
- 不擅自 commit/push；用户当次指令优先。
- 提交信息中文，写清改动、原因、真实验证数字、未验证项。
- 历史文档不回头篡改；更正用状态头/取代链接。
- 密钥值永不进日志/异常/argv/env/stdio/会话输出；配置只打印路径和长度。
