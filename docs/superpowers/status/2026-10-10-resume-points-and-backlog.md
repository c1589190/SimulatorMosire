## 2. 商户（Merchant）

### 2.1 设计与现状

- 设计书：`docs/superpowers/specs/2026-10-09-commodity-freight-and-merchant-ladder-design.md`
  （§10 = 用户 2026-10-10 逐轮裁定**补录**：商号决策步六步、三条仲裁 A1/A2/A3、现状差距表、批次 M1–M5；`06ca2abf`）。
- **现状（实测）= "承运服务承包商"，与目标不是同一层**：
  - 方向：**货主挑商号**（`rateAdjustmentPerMille` 升序 → organizationId 升序，`MerchantSettlement.select`；设计书记为 `:257`）；
  - 收入：**只有运费**（`upkeep` 是成本计提，"不移动任何余额"）；
  - 运力：`capacityPerRound` 外生 + 盈利 +5 / 亏损 −5（下限 5、上限 100000；农村累积惩罚 +2‰ 封顶 100‰）；
  - 半径：`serviceRadiusHex` 三档常数（PORTER=2 / SELF_EMPLOYED=4 / BOSS=8）；
  - **承运承诺 / 决策步全仓零命中**（实测 `grep carrierClaim|CarrierClaim|承运承诺` = 0）。
- **目标**：商号**主动挑货单**（决策步前置）→ 产出**承运承诺表** → 撮合时 A1 资产规模大者优先、A2 无承诺则倒掉（`NO_CARRIER` 具名）。

### 2.2 下一批

| 子批 | 内容 | 依赖 |
|---|---|---|
| **M1** | 商号利润算式：营收（运费 **+ 差价**）− 劳动机会成本 − 本钱占用 − 损耗 | **价差存在** |
| **M2** | 决策步：范围内需求统计 → 按利润排序 → 贪心填装到运力上限 → **承运承诺表** | M1 |
| **M3** | 承诺 + 撮合接入：**A1 资产大者优先**；**A2 无承诺 ⇒ 不成交**（`NO_CARRIER`） | M2 |
| **M4** | **运力 = 劳动**（去外生化）+ **半径由规模派生** | M2 |
| **M5** | **家户进入/退出商贩行业**（贩运收益率 vs 种地收益率）——"商人自己长出来"的最终判据 | M3 + 价差 |

### 2.3 ★ 次序观察（不是裁定）

商户 M1 的死穴是**没有价差就空转**（E 批已吃过一次）。而**口岸 P-T1 的节流 + 过境税正是"政策造出的价差"**。
⇒ **先做口岸 P-T1/P-T2，再开商户 M1–M3**，M1 的依赖才成立。
