## 4. 当前边界（必须如实）

1. **只接 continuation**：`LandProductionCycle` 只推进已有 `InProduction` land lot；IDLE lot 的自动 S3 选择尚未接。`LandProductionSettlement` 能执行显式 IDLE claim，但真实 Advance 不自动启动 IDLE。
2. **一次 Advance 一个 land day**：当前 360/真实入口按 1 tick Advance；多 tick Advance 的逐日折叠未做，类注已写明不伪造。
3. **claim/organization 仍是 owner=operator**：接受者可用显式 claim 指定 operator；自动路径只用 lot owner 作为 operator，租佃/主导者选择未接。
4. **LAND 日推进未接 labor/market 预期**：land cycle 在 population 前扣料/产出，但不重新参与 S3 劳动预算、工资、市场预期；这些仍是后续批次。
5. **投入不足不缩规模/拆 lot**：当前 `stage-input-shortfall` 原样拒绝；缩规模/拆 lot 未做。
6. **市场特定 lot 订单未接**：`MarketOrder` 的 SpecificLot/sourceLotId 字段存在，但土地 matcher/LandOrder 仍按 owner/面积，未把具体 lot 状态作为订单源携带；状态保留由 `InventoryTransferPort`/`ArableSupplySnapshots` 的 component 净差写回证明。
7. **legacy 未删除**：`ProductionProcess.stageState/progressDays/cycleInputUsedMilli` 仍服务 legacy unit/non-carrier 路径；LAND 路径不读不写它，并有双权威守卫。彻底删除需另批迁移 T4/legacy unit staged 路径。
8. **L2e 是过渡守卫，不是物理删除**：LAND 以 Map component 为唯一进度权威；双权威同时存在 fail-closed。
9. **未提交/未推送，主树源码未改**。
