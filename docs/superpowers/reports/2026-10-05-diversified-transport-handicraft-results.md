# 运输队与手工业探针结果（2026-10-05）

> 对应设计：`docs/superpowers/specs/2026-10-05-diversified-transport-handicraft.md`
> 探针：`TransportTeamProbeTest`、`HandicraftProbeTest`、`DiversifiedEconomyProbeTest`
> 运行：`./mvnw -q -Dtest='io.mosire.simos.economy.market.*Test' -Dsurefire.failIfNoSpecifiedTests=false test -pl simos-economy -am`

## 1. T1 运输队

`TransportTeamProbeTest`（2 个测试）：

- 满运力：H0→H2 运 30 粮，运费 450 全部进运输队家户，`escrow=0`；
- 运力不足：只承运 10 粮 → 运输队拿 150，剩余 30 粮的 450 仍落 `escrow`（旧抽象保留为兜底）。

结论：运费已经可以从“沉没摩擦”变成“运输队收入”；下一步只需把运力、牲畜、回程折价接进正式 M4。

## 2. H1 手工业

`HandicraftProbeTest`（1 个测试）：

- 纤维户 100 人，产 400 纤维、吃 100 粮；
- 作坊主买 400 纤维，雇 600 人的匠户（400 劳动），产 400 布；
- 发 150 钱/劳动工资 = 60,000；连续两轮产出 400 布、发 60,000 工资、雇工吃满 600 粮。

结论：原料链已经能跑通：**纤维 + 劳动 → 布**；工资可走货币腿，产出归作坊主。

## 3. D1：农村-城镇-集市多元 365×4

`DiversifiedEconomyProbeTest` 跑满 **1460 轮**（4 年）：

| 部门 | 角色 | 终局读数 |
|---|---|---|
| H0 农村 | 地主 L + 佃农 P（粮） + 纤维户 F | 农场产出 1020，租 410；P 存粮 610、钱 31,000；F 存纤维 400、钱 10,000 |
| H1 城镇 | 作坊主 O + 匠户 A（纤维→布） | 作坊产出 400 布，工资 60,000，欠薪 0；O 存布 400、钱 506,834；A 吃 592/600、钱 60,000 |
| H1 城镇 | 运输队 T | H0→H1 运 602、运费 602；H1→H0 运 400、运费 400；运输队家户钱 1,672 |
| 系统 | 人口/债务/货币/escrow | 人口 1,038（四年死亡 115、出生 123），总债务 31,087,061，总货币 32,798,486，escrow=0 |
| 价格 | 粮 / 纤维 / 布 | H0：100 / 25 / 189；H1：121 / 25 / 157 |

结论：

1. **三部门 + 运输能连续跑 4 年**，粮、纤维、布三种价格都为正；
2. **运输费不再沉没**：全部落到承运队，`transportEscrow=0`；
3. 作坊有连续原料（400 纤维/轮）和连续产出（400 布/轮），雇工工资足额（60,000/轮）；
4. 加入自然死亡/出生后，人口从 1030 缓慢增长到 1038；城镇粮价从 101 升到 121、布价从 176 降到 157，
   匠户期末食物 592/600（轻微紧张）——这是自然增长带来的需求压力，不是饥荒崩溃；
5. 仍有一个待修问题：**名义债务/货币约 3,100/3,280 万**（实物流量稳定，但信贷发行与还债回收不完全对消）；
   这属于 M3/M5 的债务-货币闭环问题，不是部门跑不动。

### 3.1 自然死亡率

- 探针现在有**自然死亡 + 出生**：每轮按百万分率结算，余数累计（避免小人口被取整抹掉）；
  出厂量级：自然死亡 25‰/年（≈68/百万/轮），出生 30‰/年（≈82/百万/轮）。
- `NaturalMortalityProbeTest`：1000 人跑 1460 轮 → 自然死亡 100、出生 120、终局 1020，全程吃饱。
- 注意：**正式运行时比探针细**——`PopulationDynamics.monthly` 有年龄档 × 性别 × 基础死亡率
  （0-14：2‰/月、15-59：1‰/月、60+：20‰/月）+ 生理压力超额死亡（阈值 300、20‰/压力点），
  出生只发生在 15-45 岁女性且受压力抑制；探针是粗出生率/粗死亡率版本。

### 3.2 货币发行口径（探针）

探针没有铸币/央行；钱是**债务融资交易的副产品**：

```text
每笔成交：买家 debt += 成交到货额；卖家收到 base 货款；运费给运输队/escrow
累计发行 creditIssued += 成交到货额
还债 wave：每户支付 min(现金, 债务)；支付额从家户现金消失，creditRepaid += 支付额
货币存量 = 初始现金 + creditIssued − creditRepaid
债务存量 = creditIssued − creditRepaid − 死亡删债（利息 0 时）
```

D1 终局（1460 轮）：

```text
初始现金 66,000
creditIssued = 221,884,895
creditRepaid = 189,152,409
deathDebtDeleted = 1,645,425
货币 = 66,000 + 221,884,895 − 189,152,409 = 32,798,486
债务 = 221,884,895 − 189,152,409 − 1,645,425 = 31,087,061
平均每轮发行 ≈ 151,976；平均每轮还款 ≈ 129,556
```

- 这不是“央行印发 3,200 万”：它是 1460 轮、每轮约 15 万交易额滚动出来的**在途信用**；
- 债务比货币少 1,645,425，正好等于自然死亡按人口比例删掉的债；
- 正式运行时的发行是显式审计的：`MoneyIssuanceRecord` 只有 `INITIAL_ENDOWMENT` / `FISCAL_ISSUE` / `WITHDRAWAL`
  三类，`MoneyAuthority`+`MoneyIssuance` 规定“一个币种一个发行人”；普通账户不得透支；
  逐币种守恒式：`Σ余额 = ΣINITIAL_ENDOWMENT + ΣFISCAL_ISSUE − ΣWITHDRAWAL`。
