### 2.2 控制方工程裁定（落地默认，用户可随时推翻）

以下不是新的用户玩法裁定；是把已有原话与 v2 的空白收成一个可执行的工程口径。

| # | 工程问题 | 落地默认 |
|---|---|---|
| E1 | S6 工资是每 tick 还是收获一次性 | **每 tick 结算**：S4 产生实际雇工劳动与 wage due，S6 每 tick 按实际劳动支付/成债。依据用户示例“报价 16 金币一 tick、获得 16+25×48/50”，且旧工程默认就是逐 tick。v2 的“收获后”更正为“每 tick 实际劳动后”；收获只决定毛产。 |
| E2 | S7 购买能否补本 tick 温饱 | **不能回溯**。S4 的 `providedFromStock` 形成本 tick 实际温饱事实；S7 买入的是未来库存，不写回本 tick 已发生的 S4 消费。S8 只读 S4 的本 tick 消费/缺口；S7 的 `purchasedFromMarket` 用于下一生产 tick 起的前瞻库存。 |
| E3 | S6 新工资债能否在本 tick S7-M2 被清偿 | **不能**。S6 新工资债进入同一 revision 的债务表，但当前 S7-M2 的还款候选排除本 tick 新工资债；最早下一市场日 M2 同池处理。否则会通过库存/土地间接实现“工资抵物”，违反“工资第一次只付货币”。 |
| E4 | 市场日账单生命周期 | 每户每 tick 仍只有一张 `DailyDemandBill` 对象。市场日 S7 在同一对象上生成只读 `marketPurchaseNeed`：`BASE_SUBSISTENCE` 与 `PRODUCTION_DAILY_EXTRA` 按“到下一市场轮”的 5 个生产 tick 前瞻；`PRODUCTION_INPUT` 只取当前实际未耕种缺口，**不乘 5**；已由 S4 `providedFromStock` 的数量不得重复下单。历史 `unmet` 只作为生存事实，不自动滚存到下一市场轮。 |
| E5 | S7“库存/债务清算” | 只做 S7-M2 债务清偿（货币 → 库存 → 标量土地），不是第二次每日消费；S4 已扣的日粮/种子不得在 S7 再扣一遍。 |
| E6 | 实际播种面积与 `u/a_i` | 每个生产周期显式记录 `sownLandMilliMu`。只有实际投入本周期生产的土地进入 `u`、`a_i`、产量份额与效率损失计算；未播种/荒置地本周期无产出份额，也不参与本周期 `u`。`a_i=0` 或 `u=0` 不参与除法；`v<=0` 视为定义故障；效率 `e_i=min(1,w_i/(a_i*v))`，固定点/饱和除法。 |
| E7 | 周期中土地被卖/抵债 | 卖地/抵债中断该土地在本周期剩余时间的生产；从下一 S3 起不再可用；已记录的该土地日效率记录不再进入最终 `B_cycle`。买方/债权人下一生产 tick 可用，不再等下一市场轮。若用户要保苗/按日分割收获，属于后续新裁定。 |
| E8 | 0 价土地用于抵债 | 0 价土地在市场可自愿成交；债务清算中**不自动拿 0 价土地冲抵本金**（价值为 0，无法确定应转数量，且会无对价剥夺债务人产权）。0 价土地不计入可抵债价值；余债保留。 |
| E9 | 土地买卖意向 | 买方需求由 S3 生产计划的实际土地缺口派生；卖方供给只来自本户本轮明确不用于生产的地或主动卖地。限价使用所属市场区 `landPrice`；`empty` 不生成土地订单，`0` 合法。无现金不妨碍形成需求，成交后未付部分走普通货币债；无供给只记 unmet。 |
| E10 | 生产聚合的权威 | `LandHolding`、家户决策、雇佣锁、当前 tick 账单副本、工资/债务/市场归 economy；每 hex 作物物理状态（实际播种、日效率、B_cycle、物理毛产）归 production，经 contract 暴露；`HexStandardAgriculture` 是组合根/economy 侧的只读运行视图，不是第三份可写状态。 |
| E11 | 全序/破平 | 家户按纯库存财富降序 → `HouseholdId` 升序。工单按单位劳动净收益降序 → hex → employer id → position ordinal/id 升序。同收益才使用该稳定序；禁止 HashMap 迭代序/墙钟/随机 UUID。 |
| E12 | 市场内价格/预算 | 商品与土地共享同一买方的现金腿/冻结；基础消费与生产投入优先于土地投资。价格每市场轮最多调整一次、下一 tick 生效，不在轮内反复试价；无价格上限。 |
| E13 | 30‰ 农具折旧 | 标准小农业 v2 不做工具/耕牛/作坊/机器，也不保留旧 30‰ 折旧作为隐藏扣减；毛产按 v2 公式与责任主体两笔账。 |
| E14 | tick0 与空订单簿 | `day % 5 == 0` 且市场表非空才开统一市场；tick0 开市不要求已有生产方式。空订单簿仍可完成 S7-M2 债务清算，但不得伪造成交。 |
| E15 | 数值单位/参数 | 土地=千分亩；金额=毫币；劳动=毫小时。`arableMilliMu(hex)`、`baseOutputPerLandTick`、`v`、`seedPerMu`、`cycleDays`、生产额外日耗、运力/运费参数、初始土地/地价/工资锚均由工程默认配置；不得把用户示例的 120/1/1 当已裁定精确夹具。 |
