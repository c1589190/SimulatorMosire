| # | 目标 | 来源 |
|---|---|---|
| G1 | **市场区只记"这一片用哪种钱"**，不再记"发行政府" | §1.5「法定货币发行者也丢掉」 |

## 4. 契约形状（冻结"世界必须长成什么样"）

### 4.1 `MarketZone`（目标形状）

```
MarketZone(
  zoneId,          // 稳定身份
  anchor,          // 锚格（城市）
  radiusHex,       // 派生半径（只读留痕）
  hexes,           // 成员格（非空、规范序、不可变）
  legalTender,     // ★ 本区"这一片用哪种钱"——唯一的货币事实
  officialRates)   // 本区官方汇率覆盖（键 = base|quote；空 = 无覆盖）
```

- ★ **`issuingGov` 删除**（§1.5）。旧档兼容：类型级 `@JsonIgnoreProperties("issuingGov")`
  （与 `HouseholdEconomy` 退役 `debts` 时同一手法，`b89efb02` 已验证该手法可行）。
- **不新增** `issuingGov` 的替代字段。要回答"谁在管这种钱"时，**从 `Government.issuable` 反查**：
  `MarketZoneBook.possibleIssuersOf(data, currencyId)` ⇒ `List<GovernmentId>`（**可多值**、规范序）。
  ⇒ 这是一个**查询**，不是状态：一份"发行关系表"会与 `issuable` 形成第二权威。

### 4.2 报价（`OfficialRate`）的归属

| 层级 | 载体 | 语义 |
|---|---|---|
| GOV 级 | `Government.officialRates`（现状不变） | "这个政府挂的价" |
| 区级 | `MarketZone.officialRates`（现状不变） | "这个区挂的价"（法律/行政定价） |

★ **两者都不含"只有发行者能挂"的限制**：任何 GOV 都能给自己**持有的**任意货币挂价（§1.4/§1.5）。
⇒ **`EconomySetOfficialRateHandler` 去掉**"GOV 必须发行 base/quote"这类校验（若存在；实测 F3 只在定义区处，
挂价处需实现方逐条核）。

### 4.3 立区准入（§1.6 裁定 = 选项一）

`DefineMarketZone` / `ReassignZoneHexes` / `MergeMarketZones` 的**准入校验保留**：

1. `bad-payload`（形状）
2. `currency-not-defined`（法定币在**世界词表**里）★ 唯一保留的货币校验
3. `anchor-in-hexes` / `anchor-missing-market`（锚格）
4. `hex-in-other-zone`（F5 互斥，**不动**）
5. `numeraire-mismatch`（F4，**保留**——它就是"这一片用同一种钱"的定义）★ 见 §5 I-M2
6. `zone-not-found` / `same-zone`（划格/合并路径）

★ **删除**：F3 的 `gov-not-registered` / `currency-not-issuable` 两条（立区不看"谁发得出"）。
★ **不新增**"至少有一个政府能发行该法定币"之类的校验（§1.6「肯定不管」）。

### 4.4 同币对多份报价（★ G3 的核心）

**目标语义**：同一币对的多份报价**全部有效、全部可见**；家户按自身需求挑最划算的接受。

- **窗口装配**（`FxRoundInput`）：逐 GOV × 每一条生效报价 ⇒ **每个窗口各一张单**进簿；
  ★ **删除 `putIfAbsent` 的"先到先得"**（F9）⇒ 同币对多窗口**并存**。
- **家户挂单价（`PairRates` 摘要）**：`bidPerMille` = 所有窗口买价中的**最高**；
  `askPerMille` = 所有窗口卖价中的**最低**（= 对手方最划算的那份）。
  ⇒ 家户"货比三家"体现在：它的买单限价取**最便宜的卖价**，自然优先吃掉最优窗口。
- **撮合**：簿内所有窗口单按 `limitPerMille` 价格优先 ⇒ 最优价先成交（现状 `matchBook` 已如此）。
- **日志**（§一.9）：同一币对出现多份**不同**报价时，**必须 INFO 具名记录**：
  谁（GOV/区）、各什么价、谁最优。**永不静默**（这是 F9 那条"静默丢弃"的正面替代）。
  同一币对多份**相同**报价 ⇒ 不刷日志（否则噪声）。

## 6. 验收判据

### 6.1 正向（真装配探针，**零手动 `core.register`**，探针打在边界之后）

| # | 判据 | 观测 |
|---|---|---|

| A2 | 立区**不要求**任何政府能发行该法定币 | 世界词表有该币即可 ⇒ **Commit**；后续该币无窗口 ⇒ 具名（不是拒绝立区） |
| A3 | 一个区内**两个政府都能挂价** | 同区两 GOV 各挂 copper/silver ⇒ 2 个窗口、都能成交 |
| A4 | **同币对多份价并存** | 两个窗口报不同价 ⇒ 家户按**最优价**成交；被压过的价**INFO 可见** |
| A5 | 家户"货比三家"成立 | 构造"窗口 A 卖价 900 / 窗口 B 卖价 950" ⇒ 家户先吃 A；A 吃光后才吃 B |
| A6 | 三不管地带家户照常比价 | 无区格上的家户仍能挂单成交（无特殊分支） |
| A7 | 反查可用 | `possibleIssuersOf(data, silver)` 返回全部 `issuable` 含银的 GOV（规范序、可多值） |
| A8 | 往返/旧档 | I-M3、I-M4 成立 |
