## 一、三层时钟

| 尺度 | 周期 | 驱动者 | 干什么 |
|---|---|---|---|
| **日** | 1 tick | `PopulationEconomyTimeParticipant` → `EconomyDayStepper.step(day)` | 吃饭、记满足率、缺口兜底、劳动投入、生产进度 |
| **月** | 30 天 | `PopulationDynamics.monthly`（social）→ 回写家户人口与劳动 | 出生 / 死亡（年龄 × 性别 × 生理压力） |
| **周期** | 120 天（按产业） | `harvest` + **初次分配** + **市场清算** + **信用** | 规模 → 产出 → 分配 → 交换 → 借贷 |

★ 与今天**完全相同**的三层时钟 —— 这次改造**不动时间结构**，只动"东西归谁、怎么移动"。

## 二、一个完整周期（120 天）

```
═══ 周期第 1 天 ═══════════════════════════════════════════════════════
 ①【投入调拨】按 relation 的「投入由谁出」栏，从指名的家户/经营者
    把种子/纤维/铁【转移】到该产业的经营主体
      · 走统一转移原语（双分录 + 守恒）
      · 取不到 ⇒ 缩规模，不凭空造（"没钱买种子的佃农 ⇒ 他的地荒着"由此成立）
      · ★ 四档默认（C3）：feudal=庄园出 · tenant=佃农家户出
                          · household=家户自出 · handicraft=作坊主出

═══ 周期内每一天 ══════════════════════════════════════════════════════
 ②【消费】每个家户从【自己的库存】吃：eaten = min(库存, 当日需求)
      · 吃不完 ⇒ 留在自己账上（**这就是储蓄**，不需要任何规则去保证）
      · 记 satisfied / unmetNeed（逐商品逐日累加，供月结算与判据读）
 ③【缺口兜底】仍缺 ⇒ 按 市场（周期末）→ 救济（留位）→ 借粮（最后手段）
 ④【劳动投入】当日劳动取自配额；产业 progressDays += 1

═══ 收获日（progressDays == cycleDays）════════════════════════════════
 ⑤【生产】规模 = min( Σ产能 , 本周期劳动 , 已调拨投入 )      ← 最短板
      毛产 = 规模 × outputPerUnit
      损耗 = 毛产 × 30‰（折旧）
      净产 = 毛产 − 损耗
 ⑥【初次分配】按 relation 逐条（priority 升序）：
      池   = pool × rate        （pool ∈ GROSS / NET / OPERATOR_SURPLUS / FIXED）
      权重 = weight ∈ {NONE, LABOR, ASSET, EQUAL}
      应付 = 池 × 本受方权重占比
      实付 = min(应付, 本期可用)      ← 上限仍是"本期产出"，不跨期挪用
      欠   = 应付 − 实付（**按规则开关**决定是否落成债权；默认消失但**读数必须报出来**）
      每一次实付 = 一条【转移】：operator → 家户（实物或货币）
      ★ operator 由 relation 指名（谁经营、谁出投入、谁拿剩余 = 同一张表）
 ⑦【入账】实物/货币直接进【家户账】—— **没有 receipt 这一步，也没有第二本账**
 ⑧【市场清算】（同格池，每周期一次）：
      供给 = 各家户留足自用后的余量（按挂牌价）
      需求 = 有【购买力】的缺口（无钱无货无信用者 = 0 有效需求，仍可能饿）
      固定价格下：供 ≥ 求 ⇒ 按需成交；求 > 供 ⇒ 按需求比例配给
      成交 = 两条【转移】（商品反向、货币正向）
      无订单簿 / 无撮合 / 无锁余额 / 无商人
 ⑨【信用】市场之后仍缺者借粮（**最后手段**）：
      额度 = min( 缺口 , 本地可贷余粮 , 借款人下期预计收入 × 倍数 )
      有【偿还】：下期收入按比例先偿债（今天完全没有这一段）
 ⑩【计息】周期末并入本金（保留；但只在真有信用时才有意义）
 ⑪【饿死判定】缺口 → 死亡（两条致死旋钮，默认 0‰ = 不致命）

═══ 每月（第 30/60/90/120 天）══════════════════════════════════════════
 ⑫【人口】出生 / 死亡 → 回写家户人口、劳动配额与劳动供给

═══ 周期交替 ═════════════════════════════════════════════════════════
 ⑬【劳动重分配】配额 + 未吸收劳动回池：
      本行业 → 本格其他行业 → 农业/普通劳动 → 失业
      ★ 带一条【缺口/工资信号】：某产业劳动缺口 > 0 ⇒ 优先吸收
        （没有这一条，"工业化吸走劳动力"永远不会出现）
 ⑭【价格】（第二版才做）P' = P × (1 + k×(D−S)/(D+S))；第一版固定价
```

## 三、数据流：从八个环，变成一条直线

```
今天（8 个互相回环的结构）                目标态（一条直线 + 三个守恒）
─────────────────────────────           ────────────────────────────────
ClassRow                                   人口（cohort：谁、多少、需求）
  ↕                                          ↓
CohortKey                                  劳动（配额 + 回池 + 信号）
  ↕                                          ↓
Industry                                   产业（技术：投入→产出，不持有任何人/货）
  ↕                                          ↓
ProductionRelation                         社会产品（毛产 − 损耗 = 净产）
  ↕                                          ↓
ActorEntry                                 初次分配（relation：谁经营/谁出投入/谁得多少）
  ↕                                          ↓
GoodsAccount          ← 只写不读           家户财产（**一本账**：实物 + 货币）
  ↕                                          ↓
cohortIntake                               市场交换（同格池清算）
  ↕                                          ↓
ClassRow.goods        ← 消费真读的         家户最终财产
  ↕                                          ↓
borrow / takeInput / …                     消费（库存减少 → 满足率）
                                             ↓
                                           人口变化（出生 / 死亡 / 迁移）
```

★ **"直线"的意思**：每一层只从上一层取输入、只向下一层交输出；
**没有任何一层回头读自己的输出**（今天 `ClassRow.goods` 正是这样一个回环）。

## 五、五个制度 + 市场 + 信用，全部只是"数据 + 发出转移"

| 制度 | 它发出什么转移 |
|---|---|
| `feudal` | 给养（按劳动 × 固定额）给四个家户 + 地租（毛产 300‰）给地主家户 + 剩余留经营者；**投入由庄园出** |
| `tenant` | 固定实物租给地主家户 + 剩余留佃农家户；**投入由佃农家户出** |
| `household` | 布分成（按劳动权重）给四个家户 + 剩余留家户；**投入自家的纤维/工具** |
| `handicraft` | 实物工资 + **货币工资**给工匠家户 + 剩余留作坊；**投入由作坊主出**（纤维 + 铁） |
| **市场** | 商品转移（卖方→买方）+ 货币转移（买方→卖方），同格池、固定价 |
| **信用** | 粮转移（债权人→债务人）+ 一条债权；偿还时反向 |
| 救济/配给 | **留位** —— 与上面同一条转移原语，将来接政府 |

★ **这是整份合成的要点**：**制度不再是"代码里的分支"，而是"关系表里的一行"**；
加一种制度 = 加一行数据，不是加一条代码路径。

## 六、三条守恒（用户点名的三条，逐条对上）

| 守恒 | 式子 | 今天的状态 |
|---|---|---|
| **产品** | 期初库存 + 本期生产 − 投入 − 消费 − 损耗 = 期末库存 | ★ **已成立**（I4.1 15/15、I4.2 五商品残差 0）；★ 改造后**过渡项 `ΔΣRowGoods` 应当消失**——它还在 ⇒ 说明还有一本账没搬完 |
| **货币** | 买方 −X = 卖方 +X；**总量只随发行/回笼变** | ★ **尚不存在**（货币规则今天只定义不结算）；★ 发行机制**还没定**（见 §七-1） |
| **人口** | 期末 = 期初 + 出生 − 死亡 + 迁入 − 迁出 | ★ **已成立**（Σ死 − Σ生 = 净减，逐值可核）；迁移尚未做（见 §七-2） |
