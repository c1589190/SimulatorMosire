> **状态**：有效，2026-11-14 用户授权实施。
> **父序列**：[节点编辑器目标运行设计](2026-11-13-node-docs-runtime-target-design.md) S8；写入嵌入 S2，查询/刷新嵌入 S1/S6。
> **本文局部取代**：父设计 S8 的“格心最近色 → 分组多条 SetTerrain”。其他节点、模块所有权和经济暂停规则保持有效。

## 1. 目标运行序列

### R0 打开地图编辑中的底图导入

工作台 `map-edit` 增加 `image-import` 子工具，不增加顶层模式。原 PNG 小面板收敛为一个完整工作区：载入底图 → 识别与修整 → 确认应用。旧 map.html 仍是只读地图页，可链接工作台；不因导入功能变成写入口。

### R1 本地底图和草稿

选择 PNG/JPEG 或点击“非洲之角示例”；示例原样复制用户的 `屏幕截图 2026-11-14 154359.png` 到 map 模块静态资源。图像解码、预处理、草稿预览都在浏览器执行，不上传原图、不调用模型。IndexedDB 保存原始 Blob、文件名、识别/网格参数及人工修整，按当前 origin + branch + mapId 区分；不持久化可直接提交的旧预览。存储失败明确提示“仅本次有效”，不谎报已保存。清除草稿时删除对应记录。

以独立的图片加载令牌防快速换文件，以恢复/参数版本防旧草稿覆盖新选择；修改识别参数只使预览失效，不能取消正在载入的新图。替换/清除时释放 Object URL。图片超出支持大小明确拒绝（32MB 文件、32M 像素上限）；无效图或全透明图不能生成可提交计划。

### R2 对齐和识别

提供三种输入解释，取样都覆盖六角形内部，不能仅取中心 3×3：

1. **晕渲地形**（示例默认）：蓝色占比估计水体；水体像素从陆地纹理统计中排除，细蓝河流不因一点命中把整格变海。陆地用局部亮度变化估计平原/丘陵/山地；支持水体阈值、地形敏感度。结果是简化类别和归一化编辑高度，不是还原绝对海拔；不自动声称识别沙漠/森林/河流网络。
2. **灰度高度**：支持黑低白高/反向、黑白校准点；灰度中位数映射 [0,1]。分类按服务器给出的地形高度带，沙漠不凭海拔自动断定；海陆阈值可调，跳过透明像素。
3. **颜色图例**：保留原最近 RGB 词表兼容能力，取格内统计并保留距离/阈值拒绝语义。

网格选择：
- “生成六角图幅”：按图像长宽比、横向格数（建议默认 72，允许 12–160）生成 pointy-top 行列矩形，轴向坐标与既有 HexGeom 一致；支持起点 q/r、裁剪范围。实际计划最多 12000 格。
- “套用当前格网”：读取当前 hexes，沿底图偏移/缩放关系在已有格内识别，仅更新命中格。

所有源图特征只影响客户端确认计划；最终载荷是 `{q,r,terrain,height}`。地形名称、颜色、可用类由当前地图 overview 提供，不能另立与后端竞争的词表。

### R3 识别预览和人工修整

模块内使用独立 Canvas2D + HexGeom 绘制原图/识别图/叠加图、六角边界、统计计数及不确定格。不得构造第二个共享主图 host 的 renderer。预览可点选/涂改格地形，并能回看原图；改变源图、网格或识别参数立即使旧计划失效并禁用应用，重新识别后才可确认。

预览冻结 branch、revision、tick、writeEpoch；应用前与实时游标比较。切换节点、分支或其他写入后禁止应用旧计划。异步识别使用递增令牌，旧响应不能恢复应用按钮。用户确认前零世界写入；非 map-edit、历史只读节点或非 image-import 子工具不得应用。

### R4 单命令原子应用

新增 map 域命令 **`map.ImportRaster`**，信封沿用 branch/expectedRevision。载荷固定：

```json
{"mode":"merge","cells":[{"q":0,"r":0,"terrain":"plains","height":0.37}]}
```

- `patch`：全部格必须已存在，只更新载荷点名格。
- `merge`：允许新增格，也更新重叠格；**不删除图外任何格，不删除/替换区域、城市、边线、通路及其他切片**。UI 明示“生成图幅，保留图外现有数据”，确认视图列新增/覆盖数。
- merge 如会扩展环绕地图键集则明确拒绝，不偷偷改变 spec/wrap。平面图是本期生成图幅的目标。
- cells 必须 1–12000；q/r 必须整数且可容纳于 int；重复坐标、未知 terrain、非数/非有限/越界 height、非法 mode、patch 图外格等均整体拒绝，不能静默截断或去重。
- 已有格用 `withHeight` 保留土地树；新格土地树为空。仅补齐使用到的标准 terrainTypes，已有定义原样保留。
- 从最终全图重切地形块，带上原 wrap；一次构造完整 GameMap，再 `MapChangeSet.between(base,target)`。不得先 withHexes 再 withTerrainBlocks，避免中间态违反分割不变式。
- handler、领域操作、窄工具/schema/描述归 simos-map；app 仅注册 handler/工具/catalog 提示。不实现 DmUsableCommand，保持 GM-only。目标路径逐格声明。
- GUI 仍走 `SimosApp.writeCommand` → `/api/command`；只提交一次。请求期间锁定文件、参数、识别、点格修整、清除、重复确认及关闭（含 Escape），相应公开操作也拒绝修改，避免旧响应覆盖另一份草稿。成功后刷新，拒绝/冲突保持待审草稿，不自动重试，不报成功。

### R5 继续完善与重启

成功后提供“进入地形修整”，回到 terrain 画刷并把主地图视图对准导入图幅；底图保持可叠加。地图高度/地形/地形块由既有 Command → ChangeSet → Revision 和 checkpoint 持久化，重启读回。IndexedDB 草稿与世界事实独立；恢复后必须重新识别确认才可写。

增加 `blank-editor` 创世选择（CLI `--profile editor --world=blank-editor`）：只创建十个空领域快照，map 带标准地形/通路词表，无人口、经济播种或模型调用；沿现有空库首次 bootstrap，不改已有世界，不改产品默认 world。用于从底图建立新世界与隔离验收。

## 4. 实现范围与责任

一个实现责任区：map 导入后端、模块前端算法/流程/样例、工作台宿主接线、blank-editor 与组合根注册；可独立编译。一个写代码 Agent；只写生产代码及必要模块资源，到 compile 通过，不写/改测试、不运行 test/verify/package、不 commit。既有 dirty 地图环绕/renderer/寻路改动保留，仅做必需的增量接线。

测试责任区在全部生产落地后统一验证，维护测试清单及必要数量变化，不弱化断言。控制方负责设计、审阅、浏览器、最终门禁及报告。

## 5. 验收判据

1. 工作台地图编辑能打开底图子工具，载用户图片与内置样例，完成识别、点改、确认、回到刷写；旧只读 map.html 不获得写权限。
2. 样例显示合理的红海/亚丁湾/印度洋轮廓和埃塞俄比亚山地纹理差异；窄河流不直接涂成整格海洋；页面明确晕渲为近似识别。
3. 灰度黑白反向、区域采样、透明/图外/混合海岸、颜色阈值 0 有确定性验证；未知输入不能悄悄套默认值。
4. 参数/图像/节点/分支/writeEpoch 变化让旧预览失效；快速换文件/恢复不能提交旧图；确认前无写，拒绝后不进完成态。
5. 导入单命令同时更新 height/terrain；patch/merge、土地树、外部格与其他组件保持、完整 ChangeSet 往返、重复/越界/未知类拒绝均覆盖；真实组合根能起。
6. IndexedDB 刷新恢复图与参数；清除可验证；存储失败明确降级；恢复不自动应用。
7. blank-editor 上导入样例后重启仍可查询同格高度/地形和格数；不会生成经济业务数据。
8. 阶段只 compile；统一测试含关键负向；完整前端门禁和适当 Java 聚焦测试通过，真实浏览器截图与命令回读留报告。

## 6. 非目标

不恢复经济/生产/文化；不做真实 DEM 下载/OCR/精确海拔反演/河流网络提取；不做全球投影或环绕重设计；不清空用户世界；不改旧 CLI 导入器；不修与本特性无关的批提交、GM 分支或多年 AI 编排；不发布外网服务。
