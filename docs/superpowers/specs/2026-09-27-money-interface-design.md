# 货币接口与币种系统（预留设计）

> **用户裁定（2026-09-27）**：
> 「**货币作为接口留好，后面写政府了要用**」+「**最好留好货币种类系统**」。
>
> ★★ **这条裁定的准确含义**：**发行机制不裁、留给政府那一轮；但"钱的形状"现在就要定对**。
> 因为形状一旦定成标量（`long money`），后面加币种就是**破坏性变更**；而定成
> `Map<CurrencyId, Long>`，政府那一轮**只需实现一个 SPI + 给一张价格表**，不用动任何形状。
>
> ★ **反面纪律（本仓刚付过学费）**：`simos-ledger` 就是"形状漂亮、零接线、收益为零"的典型，
> 本轮刚裁定**退役**（D2-A）。⇒ 本文件的预留**不许**变成第二份 ledger：
> **每一项预留都必须落在一个"今天真的会被读写"的形状上，或带一条今天就能跑到的 fail-closed 断言。**
> 凡不满足这条的（发行人的元数据表、汇率、成色），**一律不写**，只记在 §五 的"留给政府轮"。

## 一、核心：三处"钱的形状"，一次定对

| # | 形状 | 今天 | 定成什么 | 为什么现在必须定 |
|---|---|---|---|---|
| **1** | **账户余额** | `ClassRow.money`（裸 `long`，无读写语义） | **`Map<CurrencyId, Long>`**（最小单位） | 它是家户账的形状；层 0 一落地就固化 |
| **2** | **转移的货币腿** | `ledger.Transfer.money`（裸 `long`）—— 该模块正好要退役 | **`Map<CurrencyId, Long>`** | ★ **D2-A 要把 `Transfer` 的形状搬进 `economy-api`** —— 搬运那一刻顺手改，**零额外成本** |
| **3** | **价格** | 无（`netSurplus` 甚至明说"把两种商品折成一个数需要价格，而价格属 V8"） | **`(计价货币, 商品) → 价格`** | 市场池清算（层 3）需要它；口径错一次就要改读数、改结算、改用例 |

★ **判据（结构断言，现在就能写）**：**全仓不存在裸 `long` 的"钱"字段** ——
凡是钱，一律是 `Map<CurrencyId, Long>` 或带 `CurrencyId` 的复合量。

## 二、`CurrencyId`（契约，住 `simos-economy-api`）

- 与 `CommodityId` **并列**（都在 `economy-api` 的 `id` 包），形制照既有 ID：
  单参构造 + `parse`/`toString` 互为逆 + 空白即抛（**一处拼写点**）。
- **不与 `CommodityId` 合并**（理由见 §四 M3）：银作为**货币**是计价与支付手段，
  作为**商品**是可消费/可工业用的物；两件事，各有各的守恒。
- **没有 `CurrencyId` 的词表常量**（不像 `EconomyVocabulary` 的六个商品）——
  币种由**世界的创世数据**决定，不由代码钉死（信条十二：行为与值是 GM 的）。

## 三、发行点：一个 SPI + 一条 fail-closed 守卫

```
interface MoneyAuthority {                       // 住 simos-util/spi（共同上游，没人被反向依赖）
  ActorRef authorityOf(CurrencyId currency);     // 这种钱【谁】能发（政府 / 领主 / 银行…）
  Set<CurrencyId> issuable();                    // 它管哪些币种
}
```

- **发行/回笼不是新机制，而是转移原语的一个特例**：
  `发行 = 一条从"发行源"到某主体的转移`；`回笼 = 反向`。
  ⇒ 不需要第二套搬运逻辑（「先复用已有能力」）。
- **货币守恒因此可以用一条可执行的式子表达**（逐币种）：

  ```
  Σ(除发行源外的全部余额) = 期初 + 发行 − 回笼
  ⇔  「除发行源外，任何账户的货币余额不得为负」
  ```

  ★ **这就是"发行源"的定义**：它是**唯一允许为负**的账户（负 = 累计净发行）。
  与 `GoodsAccount` 的"负余额即抛"是同一族守卫，只是开了一个**具名**的口子。
- ★★ **fail-closed 的落点（今天就能跑）**：**没有注册任何 `MoneyAuthority` ⇒ 世界里没有货币** ——
  任何发行尝试**当场抛**，而不是静默变成"钱从天上掉下来"。
  ⇒ 今天的行为**完全不变**：`FIXED_MONEY_*` 继续只定义不结算（I5.3），
  而且现在多了一条**机制性理由**（不是"还没写"，是"没有发行人"）。

## 四、币种系统的四个维度：哪些现在定、哪些留给政府轮

| 维度 | 现在 | 留给政府轮（**不写**） |
|---|---|---|
| **① 种类**（银元/铜钱/纸币…） | ★ **定**：`CurrencyId` + 每币种独立余额 | 具体有哪几种 |
| **② 计价**（谁当记账单位） | ★ **定口径**：每格市场有**一个计价货币**，价格表以它计价 | 每个格用哪种 |
| **③ 兑换**（币种之间怎么换） | ★ **定形状**（见 M1） | 兑换率从哪来（市场？官定？） |
| **④ 成色/面额** | **留位**：照 `AssetClassKey.qualities` 的形制**加一维**，**不另造一套** | 具体编码哪些维度 |

★ **④ 的写法**（值得记下来，因为它防的是"同一个概念长成两套"）：
`AssetClassKey` 已经是"粗类型 + `qualities`（规范串键有序）"，
货币的成色/重量是**同一件事**（同质性键），照抄形制即可。

## 五、明确**不做**的（留给政府轮，写在这里防漂）

1. **不写** `MoneyAuthority` 的任何实现（政府切片不存在）。
2. **不写**货币的元数据表（发行人 / 可兑换商品 / 准备率 / 有效期）—— 现在写就是**猜**。
3. **不写**汇率表、不写外汇市场。
4. **不写**税、不写财政支出（`FlowRow.taxPaid` 继续恒 0）。
5. **不改** `FIXED_MONEY_WAGE / FIXED_MONEY_RENT` 的"只定义不结算"（I5.3 不变）。
   ★ 但**要给它补一个币种位**：今天"每周期 1000 毫钱"**没说是什么钱** ——
   补法是 `CompensationRule` 的 money 档带上 `CurrencyId`（见 §六 的落地时机）。

## 六、落地时机（**不在本文件实施**）

| 形状 | 落在哪一步 |
|---|---|
| `CurrencyId` 契约 | ★ **层 1**（转移原语立项时一起，因为转移腿要用它） |
| 转移的货币腿 = `Map<CurrencyId, Long>` | ★ **层 1**（与 D2-A 的 `Transfer` 搬运**同一批**） |
| 家户账户的货币余额 | ★ **层 0**（家户主体化时**一次定型**，别先写 `long` 再改） |
| `CompensationRule` 的币种位 | ★ **层 1**（`pool × weight` 拆分是同一批契约变更 —— 裁定 D5-B） |
| 价格口径 | 层 3（市场池） |
| `MoneyAuthority` SPI + 守卫 | 层 3 之前（货币结算前必须有一条 fail-closed） |

★ **一句话**：**层 0 只要记住"钱不是 `long`"，层 1 把币种位一次补齐，层 3 才需要发行人。**

## 八、裁定（2026-09-27；本节原为"待裁"，当场裁定如下）

| # | 争点 | **裁定** | 直接后果（形状层） |
|---|---|---|---|
| **M1** | 多币种怎么共存 / 怎么兑换 | ★ **每格单一计价货币 + 兑换走市场池** | ① 每格市场只有**一个记账单位**（计价货币），价格表以它计价；② **非计价货币 = 以计价货币标价的"商品"**，走**同一条市场池**清算 —— 一笔兑换就是转移原语的**货币腿**（买方付 A 币、卖方付 B 币）；③ ★ **不新增第二个兑换机制**；④ **跨政权贸易（S4）天然落在这里**（本模拟三个政权各有各的钱） |
| **M2** | 实物货币与商品的关系 | ★ **两个独立身份**，将来用"**准备关系**"连接 | ① `CurrencyId` 与 `CommodityId` **各守各的余额与守恒**（与"货币守恒独立于商品守恒"一致）；② 银作为货币 / 作为商品是**两笔账**，将来的连接是一个**字段**（某币种以某商品为准备 + 兑换率），**政府轮再加，命名空间不用动**；③ 纸币天然成立 |
| **M3** | 成色/面额 | **留位、不实现** | 照 `AssetClassKey.qualities` 的形制加一维，**不另造一套** |

★ **M1 给层 3 留下的一条形状**：市场池的"物"可以是**商品**或**另一种货币**
（池的条目类型 = `CommodityId | CurrencyId`）。这一条**现在只需记着**，实现留到层 3；
但它防的是"以后为兑换另开一条搬运通道"——那会是本仓最反对的"同一个概念长成两套"。

★★ **两条裁定合起来的一个漂亮性质**：**兑换不需要新守恒律**。
商品守恒与货币守恒各自独立成立，而一笔兑换**同时**是"商品腿变了"和"两种货币腿变了"——
落在那条**统一转移原语**上，双分录一次记完。⇒ 政府轮要做的事只剩：**实现 `MoneyAuthority`**、
**给一张价格表**、**声明准备关系** —— **一行形状都不用改**。
