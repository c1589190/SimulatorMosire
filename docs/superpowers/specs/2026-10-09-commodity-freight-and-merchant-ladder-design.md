## 4. 契约形状（冻结）

### 4.1 商品运费系数表（G1，甲方案）

```
EconomyData 第 38 组件：commodityFreightPerMille : Map<CommodityId, Long>
  · 语义：该商品的运费系数（‰），乘在整条运费上
  · 缺键 ⇒ 1000（= 现状，逐值不变）★ 这是旧世界不动的保证
  · 值域：> 0（0 或负 ⇒ 非法：“免费运输”不是“说不出价”）
```

- **唯一拼写点**：`TransportTariff.perMille(distance, radial, road, cityDiscount, ruralPenalty, commodityFreightPerMille)`
  —— 新增第 6 个入参（**整条 rate 乘该系数**）；
- `MarketTopology.freightPerMilleBetween(...)` 加商品入参（或用"逐商品查询"重载）；
- 形制照 `currencies`：`EconomyChangeSet` FieldDelta + `EconomyCodec` 键反序列化 + **往返不变式** + 旧档归一成空表；
- **GM 命令** `economy.SetCommodityFreight`（照 `SetMarketPrice` 形制：GM-only、具名拒、日志）：
  载荷 `{"commodityId":"grain","perMille":1500,"reason":"…"}`；
  拒绝：未知商品 / `perMille ≤ 0` / 与现值逐字相同（`freight-unchanged`）⇒ 具名拒且零 revision。

### 4.2 工坊制品自然需求（G2）

- **布 + 工具**进家户自然需求（与粮并列）；**不**加 `fiber`/`iron`/`wood`（中间品，家庭直接需求弱）；
- **权威仍在 Social**（`SocialProvisioning`：全局默认 + 家户覆盖，键 `(AgeBracket, Sex, CommodityId)`）
  —— ★ 不许在 economy 侧另造第二本需求权威（既有不变量）；
- 系数取值须落到**设计书可读的常量**（本设计书给不出标定值 ⇒ 由实现方按"与粮的单位可比"给出**具名常量 + 理由**，
  并在账本列出"会改变数值行为的清单"）。

### 4.3 商号利润与“运力 = 劳动”（G3）

| 项 | 目标形状 |
|---|---|
| **运力来源** | `capacityPerRound` **由投入的劳动派生**（一单位劳动换一单位运力），不再是外生常量 |
| **收入腿** | ① 运费（帮人运）；② **买卖差价**（自己低价买、运到高价卖） |
| **同一趟三条赚法** | 跑腿（只有劳动）/ 自营（有本钱）/ 两头赚（本钱 + 富余运力）——**按手里有什么取舍**，不是三套逻辑 |
| **利润** | `利润 = 运费收入 + 差价收入 − 劳动机会成本（回家种地/作坊能赚的） − 本钱占用` |
| **家户选择** | 把"开商号/加入商号"作为**新的活动**进选择器，与 `PRODUCTION`/`ARBITRAGE` **同一排序键（收益率）** |

★ **关键**：排序键仍必须"**最划算的先做、不划算的后做**"（用户阶段 1 原话），不许给商人特殊优先级。

### 4.4 商号规模决定触达范围（G5）

- `serviceRadiusHex` 由**规模**（运力 + 本钱 + 雇工）**派生**；`tier` 只作**读数/日志分类**；
- ★ 但**本批不提高创世 tier**（那是世界配置，另批）；本批只把"半径由规模派生"这条链路做出来，
  让**成长中的商号能真的扩到隔区 lane** ⇒ F8 那个瓶颈才有解。

### 4.5 区域禀赋分异（G6）

| 层次 | 由谁定 | 落点 |
|---|---|---|
| **禀赋**（天生） | **地形/资源** | 世界生成器：地形 → 资源 → **各区可建产线不同** |
| **政策**（人为） | **GOV 决策** | GOV 命令面：产业补贴 / 禁运 / 官营 / 贸易枢纽（**本批只留接口与设计，不实现全部政策**） |

★ **不许**把“区域分工”做成硬编码常量表（那是外挂配置）；必须从**地形**推出来。

## 5. 不变量

| # | 不变量 |
|---|---|
| I-F1 | **缺键 ⇒ 1000**：未设运费表的世界**逐值不变**（旧世界 `small-world`/`corridor` 必须逐值相同） |
| I-F2 | **往返不变式**：`apply(diff(base,target),base).equals(target)`（铁律 5） |
| I-F3 | **旧档可读**：缺该组件键的旧档归一成空表（= 缺键 ⇒ 1000） |
| I-F4 | **需求权威在 Social**：economy 不得另造第二本人口/劳动/需求权威 |
| I-F5 | **运力不许凭空生**：运力必须能追溯到投入的劳动（守恒） |
| I-F6 | **排序键唯一**：商号活动与生产/套利**同一收益率排序**，不许特殊优先级 |
| I-F7 | **不丢失身份**：商号/家户/单位的身份跨迁移不变 |
| I-F8 | 五条铁律与模块边界 enforcer 不变 |

## 6. 验收判据

### 6.1 正向

| # | 判据 |
|---|---|
| T1 | 设 `grain=1500` 后，同一条 lane 上**运粮的运费**是未设时的 **1.5 倍**（逐值可核） |
| T2 | 设 `tool=600` 后，运工具的运费**低于**运粮（同 lane 对比） |
| T3 | 未设表 ⇒ 运费**逐值等于** `c32f574c` 的读数 |
| T4 | 布与工具进自然需求 ⇒ 家户在缺布/缺工具时**产生购买意图**（读日志/读数可核） |
| T5 | **运力 = 劳动**：投入劳动翻倍 ⇒ 该商号本轮运力翻倍 |
| T6 | **三条赚法**：同一趟货，无本钱户只能赚运费；有本钱户自营差价（真实成交，两户身份可核） |
| T7 | **商贩自然长出**：把某 lane 的运输需求拉高 ⇒ **更多家户选择进入商贩行业**（进入数可核），且**费率被竞争压低** |
| T8 | **半径随规模派生**：商号规模变大 ⇒ 能服务**隔区 lane**（F8 那个 `LOGISTICS_CAPACITY` 下降） |
| T9 | **区域禀赋**：三区地形不同 ⇒ 各区可建产线不同（分区清单可核） |

### 6.2 负向

| # | 判据 |
|---|---|
| N1 | `perMille ≤ 0` ⇒ 具名拒 + 零 revision |
| N2 | 未知商品 ⇒ 具名拒 |
| N3 | 与现值逐字相同 ⇒ 具名拒（`freight-unchanged`，不做静默幂等） |
| N4 | 单币旧世界（`small-world`）**逐值不变**（md5 级对照） |
| N5 | 商号**不许凭空扩半径**（规模没变 ⇒ 半径不变） |

## 7. 批次顺序（依赖已定）

| 序 | 批 | 内容 | 依赖 |
|---|---|---|---|
| **1** | **A** | 同币对多份价并存 + 家户比价 + 冲突 INFO（上位文档 §7 最后一块） | — |
| **2** | **F** | **商品运费系数表 + GM 命令**（本设计书 §4.1） | 独立，可先做 |
| **3** | **D** | **工坊制品自然需求（布+工具）**（§4.2） | 独立 |
| **4** | **E2** | **区域禀赋分异**（地形 → 可建产线）（§4.5 禀赋层） | 需要 F/D 的效果可观测 |
| **5** | **M** | **商户阶梯**：运力=劳动、商号利润（运费+差价）、家户按收益率选择进入（§4.3/§4.4） | 依赖 E2（有价差才有利可图）+ A（多份价才可比） |
| **6** | **G3 复测** | 新口径：汇率收敛 + 跨区贸易真的发生 | 依赖 1–5 |

★ **为什么 M 排最后**：没有跨区价差（E2），商号赚不到差价；没有多份价（A），家户无从比价。
**顺序错了会做出“机制在、但世界不触发”的空转**（E 批已经吃过一次这个教训，见上位文档 §6.1）。
