## 2. 冻结口径（本轮六条）

| # | 口径 |
|---|---|
| S-1 | **阶层流动速度 = f(债务规模, 资产规模)**；**在 tick 最末结算**（在"本轮债务规模已算出"之后算速度、也在这时结算） |
| S-2 | **决策用上一轮的价格**（模式/需求/挂单都按上轮价估） |
| S-3 | 政府的钱：**自己获得资金可在 tick 最开始**；但**印出来的钱必须通过市场结算进入流通**；**本轮可新投入 ≤ 上一轮印的量**（滞后一环） |
| S-4 | 家户"有就买/借"，但**家户之间必须排序**：区内按**经济发达程度**排、市场区之间按**总 GDP** 排（结算顺序 = 稀缺货的分配顺序） |
| S-5 | **偿还介质按"该户预估价值最低的商品"优先**（不是"先钱后货"、也不是固定商品序） |
| S-6 | **价格表市场区内统一**（家户不各自维护价表）；**运费按距离不同，但单位运费相同**；同一时刻商品成交价"差不多" |

## 3. 现状对照（逐条：已成立 / 需改 / 冲突）

| # | 现状（file:line） | 判定 |
|---|---|---|
| S-1 | 阶层流动现在按**预期单位劳动净收益差**定权重（`ModeMigrationPolicy.plan:522-527`），速度常量 `MIGRATION_PER_MILLE=10‰/周期`、A 规则 `1000‰`，**只在关账日**结算（`EconomySettlement:3566`，晚于流水 `:3326`、早于 `DAY_END:3573`） | **需改**：改逐 tick + 新速度公式（债务/资产）+ 挪到最末 |
| S-2 | 现价表 + 轮末自适应 = 蛛网滞后一轮，**与"上一轮"天然一致** | **基本已成立**；但"一轮"是 tick / 市场轮(5 天) / 产业周期(120 天) 必须先定（见 §4-1） |
| S-3 | 政府花钱**已经只能走市场**（`govMarketMandates` → `MarketSettlement:2175-2198`/`planGovMandateOrders:2454`，无旁路）★ 但**铸币是把 `seignioragePerCycle` 直接加进国库户账户**（`GovernmentSeigniorage:101-106`，不产生 Transfer、只写 `MoneyIssuanceRecord(FISCAL_ISSUE)` 审计）⇒ **这就是"印钱绕过市场"的那条旁路** | **半成立**：需把铸币改成"经市场"；并加"上一轮印量"读口（现只有全期累计 `MoneyStock`，但可由 `MoneyIssuanceRecord.day/period` 现算） |
| S-4 | 现结算序 = **区序（zoneId 升序 `MarketZoneBook:65-73`）× 商品序 × 槽位插入序**（`:3698`；写口 `CommitOrder:24-50`） | **需改**；★ **最大风险：自指**——若"发达程度/GDP"含当日成交，则先结算者更高 ⇒ 循环 ⇒ 破 I7。**只能用"上周期持久读数"或"开盘前快照"** |
| S-5 | 现介质序 = **钱永远第一**，商品按数量（`EconomySettlement:7363-7385`）；而**估值接口与算式已在**（`HouseholdValuationBook.reservationMicro:324-356` + `DebtValuation.commonUnitValue:297-305`），只是**价目表传了 null**（`:2870/2886`） | **冲突，但改动小**：传入既有定额簿 + 介质序改 `commonUnitValue` **升序**（不造第二权威） |
| S-6 | **语义上"区内一价"已成立**：区内撮合取**锚格价**（`:4025/4034`、`:4192/4201`），播种共享一张表；跨区取**卖方格价 max**（`:7588-7596`）。但**存储是逐 hex**（`EconomyData.markets` 键 = HexCoord，95 处读点/31 文件） | **最小做法**：保留逐 hex 存储，在 `adaptPrices` 写回前加**区内对齐 pass**（现在 `next==reference` 时直接 `continue`（`:2045-2047`）⇒ 成员漂移永不被修）。换形状则触铁律 5（Codec/ChangeSet/往返 + 命令语义 + `Market.numeraire`(逐格) vs `legalTender`(逐区) 权威） |
