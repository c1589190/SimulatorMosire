## 2. 冻结口径

| # | 口径 |
|---|---|
| S-1 | **阶层流动速度 = f(债务规模, 资产规模)**；**在市场轮最末结算**（当轮债务规模算出之后） |
| S-2 | **决策用上一轮的价格**（模式/需求/挂单都按上一市场轮价估） |
| S-3 | 政府**自筹资金可在轮首**；**印出来的钱必须经市场结算进入流通**；**本轮可新投入 ≤ 上一轮印的量** |
| S-4 | 家户"有就买/借"，但**家户之间必须排序**：区内按**经济发达程度**、区间按**总 GDP**（★ 必须用上周期快照，禁自指） |
| S-5 | **偿还介质按"该户预估价值最低的商品"优先**（不是"先钱后货"、也不是固定商品序） |
| S-6 | **价格表按市场区一张**（★ v2 升级：**逐 hex 的独立价表直接退役**）；**运费按距离实时算、单位运费相同** |
| S-7 | **"一轮" = 市场轮**（开市日：每 5 天 / 关账日 / 粮紧张日）。**所有市场机制类表述（含"下一 tick"）都按市场轮读**；产业配方/关账仍按产业周期（那是生产口径） |
| S-8 | **动态价**：逐商品、逐市场轮更新；缺货**逐步涨（价本身无上限）**，供过于求**逐步跌、触底 0（白送合法）**；**速度同时取决于常数 α 与规模**（见 §2.1） |
| S-9 | **订单簿作废**：家户**不挂价**（不维护自己的价表、不设限价），只决定**数量**（卖多少 / 买多少） |

### 2.1 动态价算式（冻结）

```
每市场轮、每个商品各自算（"对于单个价目"）：

  D = 该区本轮"想要"的总量   ← 含：买不起的、被口岸闸拦下的、被运力截断的（S-6 口径：全算）
  S = 该区本轮"能上架"的总量 ← 只含真能卖的；运不出去/被拦下的不算（不自我抵消）

  D > S（缺货）: r = (D − S) / max(1, S)          // 缺货相对供给的倍数：供给越小，倍数越大
                 step‰ = min(α, ⌊α × r⌋)          // ★ "逐步"：每轮最多动 α；规模决定多快打满
                 p' = ⌊p × (1000 + step) / 1000⌋  // 价本身无上限（可逐轮复利上涨）
  S > D（滞销）: r = (S − D) / max(1, D)          // 滞销相对需求的倍数：需求越小，倍数越大
                 step‰ = min(α, ⌊α × r⌋)
                 p' = max(0, ⌊p × (1000 − step) / 1000⌋)   // 触底 0 = 白送
  D = S:         p' = p                            // 不动 ⇒ 缺省中性（不失衡的旧世界逐值不变）
```

- **α** = 具名常量（默认 **50‰/轮**），做成**可政策调的参数**；**不设上下限**（除 `p ≥ 0`）。
- **写回时区内对齐**：全区同值（见 §5 S1）。
- **成交用本轮价**（轮内价格不变），更新写回、**下一轮生效** ⇒ 即 S-2 的"上一轮价"。
- **0 价语义**沿用既有：表里**有这一行且为 0 = 免费交易（运费照付）**；**没有这一行 = 不交易**。

## 5. 架构复核（"顺便看看有没有可调整的"）

### 5.1 结构性该改（本设计直接覆盖）

1. **逐格价表退役**（S1）：键从 hex 改市场区 ⇒ 铁律 5 三件套；顺带**合并双权威** `Market.numeraire` vs `MarketZone.legalTender`。
2. **市场轮的供需输入缺失**：`MarketDemandBook` **只在关账日构建**（给迁移用）⇒ 动态价每轮都要 D/S，**需要一个"每市场轮派生"的供需视图**（可现算、不落盘）。
3. **统计缺失**：本轮成交价/均价/成交额/未满足量**都不落盘**（`MarketReport` 进程内、重启即失；`TradeHistory` 类存在但**没人喂**）⇒ S-4（GDP 快照）与 S-2（上轮价）、动态价读口**都要它** ⇒ 建议做一个**市场轮统计簿**（轻量、持久 ⇒ 铁律 5 三件套）。
4. **`adaptPrices` 的写回漏洞**：`next==reference` 直接 `continue` ⇒ 区内漂移永不修（S1 修）。
5. **铸币旁路**（S5）。
6. **排序结算与冻结中间态**（S4）：排序会改变"谁先拿到稀缺货"与冻结次序 ⇒ 必须与 `CommitOrder` 一起改，且**用上周期快照**防自指。

### 5.4 ★ 两个"大项"建议单独立项（超出本设计范围）

| 立项 | 内容 | 为什么单独立项 |
|---|---|---|
| **D1 债务式清算** | 用户 0–8 序列的 6–7 条：**先消费（一股脑全拿下，不管付不付得起）→ 全额记为债务 → 有货就还、没货挂账**。这要**取消支付能力约束**（现在 `payableMoneyOf`/预算封顶/冻结都在挡）、重定义"冻结"（没有钱可冻结 ⇒ 冻结变承诺）、并重定信用市场（D-030/D-031 借贷池）的存废 | 它替换的是**整个市场清算模型**（预算是硬约束 → 后置清偿）；与 S1–S8 正交，需独立设计书 + 独立验收（守恒/违约/破产口径） |
