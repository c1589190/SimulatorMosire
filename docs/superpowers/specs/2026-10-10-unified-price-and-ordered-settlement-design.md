### 2.1 动态价算式（冻结）

```
每市场轮、每个商品各自算（"对于单个价目"）：

  D = 该区本轮"想要"的总量   ← 含：买不起的、被口岸闸拦下的、被运力截断的（S-6 口径：全算）
  S = 该区本轮"能上架"的总量 ← 只含真能卖的；运不出去/被拦下的不算（不自我抵消）

  D > S（缺货）: r = (D − S) / max(1, S)          // 缺货相对供给的倍数：供给越小，倍数越大
                 step‰ = min(α, ⌊α × r⌋)          // ★ "逐步"：每轮最多动 α；规模决定多快打满
                 p' = ⌊p × (1000 + step) / 1000⌋  // 价本身无上限（可逐轮复利上涨）
  S > D（滞销）: r = (S − D) / max(1, D)          // 滞销相对需求的倍数：需求越小，倍数越大
                 step‰ = min(α, ⌊α × r⌋)
                 p' = max(0, min(p − 1, ⌈p × (1000 − step) / 1000⌉))  // 触底 0 = 白送；★ v3.10 与涨侧对称
  D = S:         p' = p                            // 不动 ⇒ 缺省中性（不失衡的旧世界逐值不变）
```

- **α** = 具名常量（默认 **50‰/轮**），做成**可政策调的参数**；**不设上下限**（除 `p ≥ 0`）。
- **写回时区内对齐**：全区同值（见 §6 R1）；★ R1 之后"区内对齐"是**结构上必然**（一张表），不再需要逐成员对齐循环。
- **成交用本轮价**（轮内价格不变），更新写回、**下一轮生效** ⇒ 即 S-2 的"上一轮价"。
- **0 价语义**沿用既有：表里**有这一行且为 0 = 免费交易（运费照付）**；**没有这一行 = 不交易**。
- **α 同时是防失控闸门**：D 全算（含"买不起的量"）会重新引入 2026-10-09 修掉的那条路径 ——
  "需求对价格不敏感 ⇒ 每轮乘性暴涨"（当年实测 cloth 涨到 **1.2e10 毫/单位**、跨区布匹贸易停滞、商号运费实收归 0）。
  本算式用"**每轮 ≤ α**"给它封顶；对应的验收判据见 §4.2 N-5 与 §6 R4-⑤。
- ★★ **D/S 的"不对称"是刻意的（v3.5 控制方裁定，回代码核过）**：**D 不扣"运力截断量"**（买家的"想要"就是全额需求；运力没运走 ≠ 没人要），
  **S 仍扣**（只算真能上架的）。缺货压力只能从这条不对称里来 —— 正是用户"缺货价格应该逐步增加"的通道。
  （W2 §9-③ 的更正也对：**口岸闸拦下的量本来就在 D 里**（D 取自买槽 `order.quantity()` 全额），再加会重复计数 ⇒ 不新增口岸项。）
- ★★ **整数毫位的最小步进（v3.5 控制方裁定，补进冻结算式）**：
  ```
  缺货且 p > 0：  p' = max(p + 1, ⌊p × (1000 + step) / 1000⌋)
  ```
  因为价格以**毫**为最小单位，`p < ⌈1000/step⌉`（α=50‰ ⇒ **p < 20 毫**）时纯取整会**恒等不动**，
  与"缺货价格应该逐步增加"直接矛盾（真实世界的 1 毫粮价会永不涨）。`+1 毫` = 整数粒度下最小的"逐步"，
  **不是第二条公式**。滞销侧**不需要**对称例外：`max(0, ⌊p×(1000−step)/1000⌋)` 在 p=1 时已经到 0（白送）。
- ★ **α = 0 的语义（v3.8 控制方确认，W2-fix 具名上报）**：**α=0 ⇒ 该区价格不随供需变动**（缺货侧**不**走"+1 毫"最小步进）——
  这是"GM 把价格钉死"的合法状态；最小步进只在 **α > 0** 时生效。实现取 fail-closed：`step <= 0 ⇒ return price`。

### 6.0 为什么是这个顺序

```
W1 状态与账 ─→ W2 清算与价格 ─→ W3 人的进出 ─→ W4 家户的位置 ─→ W5 钱的来源 ─→ W6 总验收
（形状+仪表）  （清算+定价）    （死亡率移交）  （排序+阶层滑落）  （铸币入市）   （读数+标定）
```

- **W1 先动形状与账**：逐区价表退役 + 统计簿要动全仓读点（§3.1-1 的 130~150 个改点）与同一批文件；
  先做完，后面的语义批次才不必在旧形状上写一遍、再改一遍。★ **W1 不许改数值行为**（判据 = 既有语义量逐值不变）。
- **W2 是机制本体**：取消支付能力硬约束（先消费、全额记债、有货就还）与动态价（§2.1 + D 全算 + 白送）
  是同一件事的两面 —— 前者一落地，"买不起"这个概念消失 ⇒ **D 天然就是"全算"**，不必先写临时补丁再拆。
  ★ 本批**同时改生产方式本身**（S-10，用户第五批补充）：把成员口粮**并进"生产花费"**，家户**只预估这一个量**并购买，
  不再单独计算"一日口粮"。
- **W3 定"谁活着"**：饿死口径由 Social 算；W4/W5 的读数都必须跑在最终死亡率上，否则白标一遍。
- **W4 定"谁先拿到"**：排序是稀缺品的分配装置；阶层滑落（速度、逐级不跳级）与它同属"家户在市场里的相对位置"。
- **W5 定"钱从哪来"**：铸币入市（生产方式 + 上轮印量上限 + 货币 = 政府债务）独立成批、最后接上，
  以免新钱干扰 W2 的价格观察。
- **W6 不是"再写代码"**：真实 world 读数 + 守恒 + 性能 + B2 分段等价 + 统一测试批 + 标定 + 文档关账。
