# 市场与债务架构 v0（2026-10-04）

> **性质**：本轮对话冻结的**目标结构**，不是当前生产代码的现状。实现分阶段，见
> `docs/superpowers/plans/2026-10-04-market-debt-implementation-plan.md`。
> **来源**：用户 2026-10-04 对话裁定 + 既有设计（`2026-09-28-pre-modern-economy-development-plan.md` §S2.3 的
> `planEntries`/`ProductionCandidate`）。
> **范围**：家户抽象单位、生产方式/阶层位置、生产—市场—债务循环、单市场区价格动力、全局货币/信贷池。
> **非范围（本版不做）**：完整生产运行时、脚夫阶层状态、跨市场区/汇率、风险溢价、价格归零后的货/钱去向。

## 0. 一句话

家户是**抽象经济单位**；每轮先定生产方式、估生产需求、还债、把剩余挂到**每格一个中央池**；买家按**总财富降序**、
无出价、按卖家 `ask` 成交，成交直接记**单边债务**；价格由 `ref`（上一 tick 每格简单平均成交价）+ 规则 A/B/C 驱动；
信贷池承担坏账；国家用锚定兑换和 GM 参数调控。

## 2. 每轮主循环

```text
① 选生产方式
   已有 unit 延续；无生计/闲置/新进入走 planEntries + ProductionCandidate；
   产出 desiredScale（受资产/劳动/投入/试产上限约束）。

② 估 C1（方案甲）
   C1 = desiredScale × inputPerUnit + 预估口粮

③ 还债 wave
   多边净额，按区域市场交换本位；
   库存多的产品优先还；
   “意思意思”扣一部分，不追求还清。

④ 留生产、算需求
   A1 = 逐商品 max(0, A − C1)
   C2 = 逐商品 max(0, C1 − A)
   C3 = C2 + 剩余债务的本位需求

⑤ 市场（先把同一个市场区做好）
   每格一份订单表：A1 挂卖；
   首次定价 + ref + 规则 A/B/C；
   买家按总财富降序、无出价、按最低 ask 成交；
   跨格运输：本格脚夫抽象产能 + 地形距离；运力不足富者优先；
   成交直接记买家债务；低于成本差额也加债务；
   市场区内多边净额。

⑥ 生产（放最后）
   从 A 直接扣口粮；
   吃饱度 = eaten / needFood；
   有效劳动 = availableLabor × 吃饱度（或 max(300‰, 吃饱度)）；
   actualScale = min(目标规模, 有效劳动/laborPerUnit, A[投入]/inputPerUnit, 资产容量)；
   扣投入、加产出回 A。

⑦ 债务
   利息照算；债务无限滚动；
   只有“阶层下滑事件”和“人口死亡”才减债；
   债务随人口/阶层迁移；死亡删债；
   债务规模增加 → 阶层下滑速度增加。
```

## 3. 价格规则（冻结）

### 3.1 单位与价格表

- 价格单位：**钱 / 1 单位商品**（毫银/商品单位，整数定点）。
- 每个家户维护自己的**出售表**：
  ```text
  商品 id / 可售数量 / cost / ref / ask / 可接受支付方式
  ```
- 粮本位只作参考换算，不改变“用钱挂牌”。

### 3.2 cost：按生产配方和当前价格估算

```text
cost(g) = Σ_i 投入量_i × 当前价格_i
        + laborPerUnit × 最低生存工资
        + 地租/资产租 + 运输成本 + 债务服务
        − 副产品按市价的预期收入
```

- 家户即使**不生产** g，也按自己掌握的配方估一个 cost；
- 联合产出用“主产品 + 副产品抵扣”（首选），或收入占比；
- 无价商品标 `unpriced`，不硬折。

### 3.3 ref 与 ask

- `ref(g, hex)`：上一 tick **本格该商品简单平均成交价**；不分品质；含运输成本。
- 初始值：GM 给一个**初始 GM 成交价**；首次卖出由产出者自己定价。
- 规则：
  ```text
  若 ref > 0:
      ask = ref
      ★ 单个家户一旦出现生产过剩卖不掉，下一 tick 立刻降价尝试出售
  若 ref == 0:
      产出者自定价；可用 GM 初始成交价作基准
  ```

### 3.4 规则 A/B/C

```text
规则 A（卖不掉 → 降价）：
  未售比例 > 阈值：
     ref_next = ref × (1 − α_down × 未售比例)
     ★ 不设成本下限，可以低于成本；最低到 0

规则 B（缺货 → 涨价）：
  有效需求 > 供给：
     ref_next = ref × (1 + α_up × 缺口比例)
     上限 p_max

规则 C（无成交 → 归零）：
  本轮完全无成交 ⇒ ref_next = 0，下一次由产出者重新定价
```

- 所有参数 GM 可调：`α_up`、`α_down`、未售阈值、缺口阈值、`p_max`、GM 初始价、运输成本常量。
- 低于成本的差额**直接加在买家债务上**；生产端可以因此转变生产方式/缩产/退出。

## 4. 市场清算

- 买家**不挂收购价**；议价权通过**购买优先级**体现。
- 总财富：
  ```text
  wealth(h) = 钱 + Σ商品 × 本格价 + Σ资产 × 本格价
  不含债权（本设计不记对面债权）；不扣债务
  ```
- 买家按 wealth 降序；卖家按 ask 升序；从最低 ask 开始成交；成交价 = ask。
- 每笔成交：买家 `A += 商品`、`debt += 金额`；卖家 `A -= 商品`，从信贷池收到钱。
- 市场区内多边净额；跨格运输成本由本格脚夫抽象产能 + 地形距离决定；运力不可存储，不足时富者优先。

## 5. 债务与货币

- **单边负债**：只记债务人欠多少，不记对面债权；有些债生来是烂的。
- 债务按市场区交换本位计量；多边净额；利息照算；库存多先还。
- 债务跟人口/阶层迁移；死亡删债；债规模↑ → 阶层下滑速度↑。
- **亏损**：售价低于成本的差额加债务；生产端可转变生产方式。
- **信贷池**：承担坏账；风险溢价暂不做。
- **货币**：更全局；价格用钱；钱有固定锚定物；国家决定兑换；
  发行/回笼/信用创造全部显式记账（本版先按探针简化）。
- **发行权逐国显式**：`Government.issuable` 空集 = 非发行人；同一币种只能有一个发行主体；
  运行期发行/回笼必须落 `MoneyIssuanceRecord`（`INITIAL_ENDOWMENT`/`FISCAL_ISSUE`/`WITHDRAWAL`），
  普通账户不得透支；“有没有发行权”不能靠缺省或发行记录空表来猜。
