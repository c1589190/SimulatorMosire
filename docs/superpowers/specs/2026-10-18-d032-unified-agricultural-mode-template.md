## §1 结论

- **土地在 production 里不是独立生产体系**：它只是 `AssetKind.LAND` 这个**生产能力资产**的一档，和 `CATTLE/SMALL_TOOL/LARGE_TOOL/WORKSHOP/MACHINE/SHIP` 同属 `capacityPerUnit`；不是 `dailyInputPerUnit` / `cycleInputPerUnit` 那种会被消耗的原料。
- **土地之所以在 economy 里被单列，是经济/政策属性，不是生产公式属性**：
  1. 不可由生产配方制造，hex 供给有限；
  2. 有地点，不能跨 hex 当同质库存；
  3. 是存量资产/所有权凭证，不是每周期消耗品；
  4. 用户已定：计入纯库存财富、可作为债务清偿资产、可交易；
  5. 本轮只启用 `LAND` 这一档；工具/作坊等同类资产暂不进入土地市场/纯财富。
- **正确抽象**：unified market 支持“商品订单 + 生产能力资产订单”两种变体；本轮资产订单只允许 `AssetKind.LAND`。不得写成 `if (land)` 的第二个市场，也不得把土地塞回 `HouseholdGoods`。
- **无级农业模板**：只保留**一个** `grain_farm` 生产方式模板；所有农村家户（有地/无地、富/穷）都走同一套位置/角色/工资/产出规则。地主/富农/中农/贫农/雇农只作为**结算后的读数投影**，不得参与生产方式选择。

## §2 一个模板，不是四个 mode

### 2.1 生产方式定义（production 权威）

建议只定义一个农业生产 mode（id 由工程定，暂记 `grain_farm`）：

```text
mode = grain_farm
capacityPerUnit = { LAND: 1000 }        // 1 个规模单位 = 1 亩（1000 千分亩）
cycleInputPerUnit = { LAND: { grain: seedPerMu } }  // 种子是消耗品，按周期扣
dailyInputPerUnit = {}                  // 或按实际配方
laborPerUnit = 每单位规模所需劳动
outputPerUnit = { grain: ..., fiber: ... }
roles:
  operator        PRODUCT_SHARE, share=1000（组织者/经营者/自家劳动）
  hired_laborer   MONEY_WAGE, share=0（市场工资锚，按实际劳动结算）
```

- `LAND` 在 `capacityPerUnit` 里是**产能上限**，不是消耗；生产后土地仍在。
- 土地**数量/质量按 hex**；**价格按市场区一个价**（由 economy 提供），hex 不单独形成地价。
- `grain` 在 `cycleInputPerUnit` 里是**种子**，会消耗；它与土地不是同一类“生产花费”。
- 如果同一块土地还产纤维，纤维是 `outputPerUnit` 的副产，不另造土地账。
- `operator` 角色承载经营者/自家劳动；`hired_laborer` 角色承载雇工。**没有 `landlord` / `tenant_operator` / `family_farmer` / `wage_farmer` 这些按阶级拆开的角色。**

### 2.2 谁可以组织生产

- 任何**拥有土地**的家户，都可以在自己的土地上组织 `grain_farm` 生产；不论它被读成地主、富农、中农还是贫农。
- 没有土地的家户不能自耕；它只能：
  1. 作为 `hired_laborer` 向别人的农场提供劳动；
  2. 在统一市场买地；买到后**下一市场轮**才能组织生产；
  3. 无业/基本消费。
- 土地所有者不能用自己的劳动耕种其他 hex 的土地；跨 hex 土地必须雇佣土地所在 hex 的当地雇农（用户已定）。
- 不保留租约/租地关系。土地所有者不种，就只能闲置或卖出；不能靠“收租”自动获得产出。

### 2.3 自耕—雇佣是连续选择，不是模式切换

同一个家户、同一个 `grain_farm` 实例内，允许同时有：

- 自家劳动（`operator` 角色，产品份额）；
- 雇工劳动（`hired_laborer` 角色，货币工资）。

选择规则（工程默认，P3 约束设计书细化）：

1. 家户先按劳动预算、自有土地、投入和利润率，算出想经营的农场规模与所需劳动；
2. 自家劳动可投入自己的农场，也可作为雇工投入别的农场；两者用同一“单位劳动净收益”比较；
3. 自家劳动不足时，若多雇一单位劳动的预期边际净收益 > 市场工资 + 具名风险项，则挂 `hired_laborer` 需求；
4. 自家劳动足够时，不强制雇工；土地多、自家劳动少 ⇒ 自然倾向雇工；土地少、自家劳动多 ⇒ 自然倾向自耕或外出做工；
5. 预期净收益 ≤ 0 的位置不选；失败位置劳动转无业；
6. 不写 `if (class == LANDLORD)` / `if (land > X) mode = ...`；阶级标签不进入选择键。

> 可选工程参数：雇工管理/监督成本、风险溢价、最小农场规模。默认先取 0 或可配置值；不得把它们伪装成用户裁定。

### 2.4 两轮生产方式计算

模板必须支持单家户在同一市场轮做两次计算：

1. **第一轮（预期）**：用上一轮实际库存/土地、预期价格/工资、Social 劳动预算，选择本户的 `grain_farm` 规模、自家劳动、雇工需求、商品/土地买卖意向；生成 `ExpectedProductionPlan` 和雇佣锁。
2. **第二轮（实际）**：统一市场和每日消费后，用实际库存/土地/劳动重新计算非雇佣部分；雇佣锁、新买土地不可用、第二轮不得下单是硬约束；目标仍是最大化本户实际净收益。

两轮共用同一 `positionNet / positionYieldPerLabor` 算式；第二轮不得另写一套“实际版利润公式”，也不得为了第二轮更优而改第一轮锁定的雇佣关系。详见 tick contract §3.1.1。

## §3 产出、工资与剩余

```text
农场总产出 = f(实际规模, 土地质量, 劳动贡献, 经验)
雇工工资 = 市场工资锚(市场区 × 生产方式 × hired_laborer) × 实际劳动
经营者剩余 = 总产出价值 − 消耗投入 − 雇工工资
```

- `operator` 是剩余索取者；即使经营者本人不下地，也可以组织生产并领取剩余（用户已定：地主可以零劳动收租/收剩余）。
- `hired_laborer` 只拿工资；工资第一次只付货币；未付成普通家户货币债；不拿库存抵工资。
- 没有“地租”这一层；土地所有权通过“经营者身份 + 剩余”实现，不通过 rent 规则。
- 产出与入库同一生产结算环节；工资按实际劳动结算；预计/实际使用同一套 probe/execute 条件（审计 A2/A3）。

## §4 阶级标签只做投影

- `landlord / rich_peasant / middle_peasant / poor_peasant / landless_laborer` 可以作为**结算后读数/UI 投影**保留；
- 不得作为：
  - 生产方式 id / 角色 id；
  - 候选生产方式过滤条件；
  - 初始位置映射；
  - 工资/价格/土地需求的输入。
- 投影输入只用可观察量：土地面积/质量、劳动预算、实际自耕劳动、雇工劳动、工资收入、经营剩余、债务、经验。
- 同一家在两个市场轮之间可以因买地/卖地/人口变化改变投影标签，但 `grain_farm` 模板与位置规则不变。

## §5 初始世界数据

- 标准预设：每个农村家户有差异的初始财产与对应规模土地；允许存在无地家户。
- 不再按 `poor_peasant → wage_farm`、`middle/rich_peasant → family_farm`、`landlord → tenancy_fixed_kind` 建位置；
  所有有地家户默认获得同一个 `grain_farm` 模板的组织资格。
- 0 元公共土地只作测试预设，不作标准世界默认。
- 初始土地分布必须满足：每 hex `Σ 家户土地 = 该 hex 可分配土地`；总量守恒；质量系数可在工程默认中配置。

## §6 与 tick 契约的接线

- **M3 预期编排**：有地家户按 `grain_farm` 计算自有土地可经营规模、自家劳动投入、雇工需求、商品/土地买卖意向；无地家户只生成 `hired_laborer` 供给/无业。
- **M4 统一市场**：商品订单与土地订单同一市场；土地订单只改变所有权/hex 归属，不改变本轮已锁定的生产计划；本轮取得土地下一轮才可用。
- **M6 实际编排**：雇佣关系锁死；自家劳动+雇工劳动按锁定份额投入；实际库存不足则失败位置转无业；非雇佣小生产可重排。
- **M7 生产执行**：`LAND` 是容量约束，种子是消耗投入，产出与入库同环节。
- **M8 工资**：`hired_laborer` 只拿货币工资；未付成普通债；不抵物。
- **M2 债务**：土地可直接抵债；抵债取得土地本轮不用；没有 `Pledge`。

## §7 验收判据

1. 同一个 `grain_farm` mode 下，大地少劳户选择雇工，小地多劳户选择自耕/少雇工；两者不是两个 mode。
2. 把家户的阶级投影从“富农”改成“贫农”，生产选择结果不变；把土地/劳动/资金改变，结果按公式改变。
3. 无地户不能自耕；可被雇；买地后下一轮可以组织 `grain_farm`。
4. 跨 hex 土地：所有者不能用自己的劳动耕种；必须出现本地 `hired_laborer` 才能生产。
5. 没有 `tenancy_*` / `landlord` / `family_farmer` 作为农村默认 mode/role 选择键。
6. 种子是周期消耗；土地是产能，不因生产消失；产出不得超过 `min(土地, 劳动, 投入)`。
7. 预计/实际产出使用同一逐参与户条件；零劳动经营者 + posting 招工不被预计器误判 labor-short。
8. 阶级投影只读；删除/改坏投影不得改变生产、工资、土地或市场结果。
