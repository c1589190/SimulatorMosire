## 1. 工资欠薪不计息

所有由未支付工资形成的欠薪债务，利率为零；不能默默继承旧工资资本化路径的 legacy 20‰，也不能只给新 posting 路径零息而让同类工资欠款继续生息。

本裁决不取消本金、实际偿还或其他既有债务规则，不将全世界普通借贷统一改为无息。工资债来源要可识别，便于保证“不计息”适用于工资欠款而不误改其他贷款。

实际利息/债务结算归 economy；账户变更仍走既有账户所有者的变更集。旧存档按 Alpha 纪律重建，不额外要求写旧档兼容迁移。

## 2. 不从业由条件判定，撤回简单缺行布尔默认问题

用户已定条件：

> 任何家户只要条件允许（从事任何可从事的生产方式都没法换取下一tick的生存所需）都可以被裁决为不从业

落实要求：

- 此资格适用于任何家户，不限预先标成流民/无产者，也不能被任意缺行默认或某户 allowIdle=false 静默否决。
- 判断本户真正可从事的方式；资格、权益/资源、岗位、劳动预算及既有迁移限制继续生效，不虚造自营土地或工作机会。
- 必须按下一 tick 生存目标判断，不能拿“利润大于零”替代。某户每 tick 所需为 10，最好的可行谋生所得仅 1，仍处于用户允许裁决不从业的情形，不能因 1>0 就取消其资格。
- “可以被裁决”不等于所有不足者必须自动闲置，也不保证从业者必能维生；选择/裁决结果须明确，不仅设置了一个永远不可能胜出的 idle 候选。
- 闲置仍消耗生活物资、保留实际缺口及 Social 后续影响，不产生工资、免费食物、生产经验或新生产权益。

**工程落细要求**：以整个家户既有择业/劳动配置为比较对象，多个可兼做方式的组合不得重复使用同一预算；不能单看各副业单独不足就误判合计也不足。对零可行候选，返回具名“无可行方式/生存不足”状态，不抛空集合最大值。

## 3. 预测、生存实物与时间尺度

生存需求基准由 Social 权威提供；economy 使用已有家户资源、可执行方案所得、当前报价、本地价格与商品可达/供给事实做下一 tick 的经济预测。设计须写清比较时点、库存和所得的覆盖方式，避免对同一生活需求重复扣减。

- 整季收获不能直接当成下一 tick 已可吃到的粮；收益比较的周期窗口与短期生存预测分开。
- 当前报价合法为零，低价合法；资格判定不等于给所有雇主强制一个维生工资底线。
- U21 继续有效：不用历史欠薪/兑付率加信誉折扣；没有收到的钱粮不能当成已实现消费。预测可能落空，实际缺口仍反馈饱食度和劳动能力。
- 不新增预付口粮、工资预支、自动救济或无限借款来填平缺口。
- 新判定必须进入现有同一套经济选择/统一分配链，不在 app 另造一套家户决策。

## 4. 抵物折价可配置，允许低于 bid

固定“当地 bid 就是唯一折价尺”的工程默认撤回。生产方式的支付条款须可配置抵物折价策略/系数，允许比 bid 更低，不需用户逐个指定所有数值。

**工程表达示例（不是用户固定公式）**：

```text
抵物单位折价 = 当地所选参考价格 × 可配置折价系数
```

参考可以选当地 bid，系数可以低于 1；不把 1 写死。策略及参数要有明确单一来源、版本和生效规则，不在 production/economy 各保存一份可独立修改的配置。

付款顺序仍为：对应货币 → 可支付活动库存数量从多到少 → 剩余债务。折价尺改变的是同额工资需要抵多少物，不改变数量排序；折价更低时，同额工资需要更多实物。

缺价、折价后为零或缺必要币种事实时，不能按任意价/1:1 清债或无限支付数量；该商品具名不可用于本次抵付，剩余欠款保留。取整须保证已付价值与剩余本金不重复计算，不因配置系数截断将已付伪造成清偿。再生产权益/已占用资料继续排除。

## 5. 明确模块边界

| 内容 | 权威与责任 |
|---|---|
| 角色、配方、经验/资格、产品份额、支付物规则、可配置的抵物折价策略/参数定义 | **production** 的生产方式定义面；只声明规则和纯配置，不读取市场、钱包或他户状态 |
| 当前市场价格、报价/调价、候选收入成本、生存目标经济可达性、不从业资格/选择、统一资源分配、抵物估值与工资/欠薪结算 | **economy**；读取 production 规则、Social 生存需求和原所有者资源事实，计算与变更本域状态 |
| 生存需求/人口结构、饱食度、饥饿对劳动能力的实际影响、人口后果 | **Social**；不读取市场报价来替 economy 选职业，不由 economy 重写饥饿/人口公式 |
| 实际货币和商品账户余额、冻结、真实转移落账 | **actor 等原账户所有者**；economy 经既有转移与 ChangeSet 路径请求应用，不能直接改其 Map |
| 再生产权益、占用和最终可支付库存事实 | 既有权益/占用所有者的唯一权威及只读契约；D4 明确排除量，W3 不二次扣减、不回退整账户余额 |
| 组合输入、时序与同 Revision 原子提交 | **app/Core**；只调度，不实现生存判定、工资定价、抵物折价或利息公式 |

折价的**规则定义**在 production，调用市场参考价并算出本次付款价值的**执行**在 economy；production 不因此产生对 economy 实现的反向依赖。值类型继续放合法契约面，economy-api 不反向引用 production 类型。

不从业是经济活动的判定结果，不是 production 自行改家户人口/阶层，也不授权 economy 改其他领域持久状态。
