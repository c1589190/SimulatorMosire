# 多元化生产环境：运输队伍与手工业（2026-10-05）

> 来源：用户 2026-10-05 裁定——“不用看是否歉收，生产环境本来就是多元化的；要不要加入运输队伍和手工业？”
> 关联：`2026-10-04-market-debt-architecture.md`（市场/债务）、
> `2026-10-05-tenancy-wage-production-modes.md`（农业生产方式）、
> `docs/superpowers/reports/2026-10-05-tenancy-wage-cycle-results.md`（现有单部门探针结果）。
> 结论：**要加。运输队把“运输成本”从沉没 escrow 变成服务部门收入；手工业把农业剩余/劳动接入城乡分工。
> 但两者不是同一批任务，先 Probe 后正式。**

## 0. 为什么必须加

当前小世界只有粮 + 布：

- 布是织户用**劳动直接产出**的（无原料、无城乡、无作坊资本）；
- 跨格运输费落进 `transportEscrow` 沉没，没有脚夫/船帮/车马队收入；
- 长期跑到 365×4 后，第一年冲击就会把需求结构打塌，经济进入囤粮 + 高名义债务的停滞均衡，
  没有任何部门能吸收劳动、也没有运输收入回流来闭合货币循环。

所以加入两块：

1. **运输队伍**：闭合“空间”这一维——货物运输需要运力，运力有成本/收入，运费回到家户账上并再次消费。
2. **手工业**：闭合“原料—加工—消费”这一维——农业不只是产粮，还产纤维/羊毛等原料；
   城镇作坊买原料、雇工、卖布，农民/地主买布，工具反哺农业。

## 1. 运输队伍（脚夫/船帮/车马队）

### 1.1 组织形态

- 不是新“商品”那么简单，而是一种 **ProductionOrganization**：
  - `operator` = 运输队家户 / 行会 / 船帮；
  - `laborSource` = `WAGE`（雇工）或 `FAMILY`（家庭脚夫）；
  - `assetSources` = 车、船、牲畜、驮具（数量进入运力）；
  - `output` = 运输服务（建议作为显式 service commodity，或先用 `TransportTeam` 类型表达）。
- 一个运输队负责一组 lane：`(fromHex, toHex, direction)`；回程可空载折价。

### 1.2 运力与收费

```text
capacity(team, round) = 载具数 × 单载量 × 路况/天气 × 劳动可用
                       （不可储存；每轮重置）
fee(trade) = 重量 × 距离 × 费率  或  从价费率 × 货值
```

- 现有探针的 `baseTransportPerMille + perHexTransportPerMille × distance` 保留为**出厂参数**；
  区别是：这笔钱不再进 `transportEscrow`，而是进入承运的运输队账户。
- 运力不足时按优先级分配：高价值、易腐、富者优先；走不完的货顺延或改价。
- 运输队也要吃饭：脚夫家户纳入 `households`，有 `need(GRAIN/CLOTH)`，运费收入用于买粮、买布、修工具。

### 1.3 与市场的关系

- 市场匹配仍由买家按财富降序、按最低到货价选卖方；
- 选中某条 lane 后，先看有没有运输队能承运：
  - 有 → 运费记运输队；运输队 `lastUnitsMoved/lastFeeEarned` 入读数；
  - 没有/运力不足 → 部分走 escrow 或交易做不成（M4 再定，先用“部分承运 + 剩余 escrow”）。
- 这把运输从“外部摩擦”变成“可就业、可收入、可破产”的部门，货币循环才闭合。

## 2. 手工业（作坊/匠户）

### 2.1 原料链

最低限度先加 **纤维/羊毛** 这类农业原料：

```text
农业：粮 + 纤维/羊毛
手工业：纤维/羊毛 + 劳动 + 工具 → 布
```

- 农村副业：家户农闲织布（`LaborSource.FAMILY`，产出归家户，自给或卖布）；
- 城镇作坊：作坊主出场地/工具/原料，雇工生产（`LaborSource.WAGE`，产出归作坊主，发钱/粮工资）；
- 独立匠户：自营 + 自己劳动（`MIXED` / `SELF_SUBSISTENCE` 档）。

### 2.2 组织与生产关系

- `ProductionMode`：`handicraft_workshop`（或复用现有 `handicraft` 档，但语义从“布=劳动直接产出”改成“纤维 + 劳动 → 布”）；
- `ProductionRelation`：
  - `operator` = 作坊主 / 匠户；
  - `inputSupplier` = 作坊主（买纤维/工具）或家户自出；
  - `residualOwner` = 作坊主（雇工制）或家户（副业）；
  - `laborSource` = `WAGE` / `FAMILY`；
  - `rules` 里用 `FIXED_IN_KIND_PER_LABOR` / `FIXED_MONEY_WAGE` / `OUTPUT_SHARE` 表达工资。
- 作坊会因原料贵、布价低而**亏损停产或转产**；这正是后面“生产方式自主选择”的用武之地。

### 2.3 城乡分工与需求

- 城镇人口不种粮，靠工资买粮；农村人口提供粮 + 原料，买布/工具；
- 作坊/匠户需要工具、燃料等（后续可加），先保持“纤维 + 劳动 → 布”的最小闭环；
- 运输队把“农村粮/纤维 → 城镇，城镇布 → 农村”连起来。

## 3. 多元 365×4 测试小世界

建议的探针世界（可比现有单部门版复杂，但仍是纯 Java 测试模型）：

| 格 | 部门 | 角色 |
|---|---|---|
| H0 农村 | 农业 | 地主、佃农/雇农；产粮 + 纤维（先由独立纤维户或农业副产） |
| H1 城镇 | 手工业 | 作坊主 + 雇工/匠户；买纤维、产布、卖布 |
| H2 集市/港口 | 运输/商业 | 脚夫/船帮 lane H0↔H1↔H2；可能加一个商人/仓库户 |
| 跨格 | 市场 | 买家按财富降序、到货价含运费；运费付给承运运输队 |

判据（跑 1460 轮）：

1. 粮、纤维、布三种价格都出现且非零；
2. 作坊有连续原料、有连续产出；不会因为一次歉收就永久停产；
3. 运输队有收入、吃得饱，运费不再沉没；
4. 城乡人口不死光；各 sector 债务/货币可对账；
5. 若某部门长期亏损，能被“生产方式选择”停产/转产（后续再接）。

## 5. 需要用户裁定

1. 运输队是**独立部门**（有脚夫家户、运力、收入）还是先只做“市场运费收款方”抽象？
2. 手工业原料先做 **纤维/羊毛 → 布**，还是直接布 + 工具/燃料更复杂链？
3. 城镇人口吃粮是否完全靠市场，还是保留一部分农村自给/救济？
4. 运输收费按**重量×距离**，还是**从价**（货值比例）？
5. 亏损选择：只“停产/退出”，还是“佃农↔雇农、副业↔作坊”跨模式切换？切换成本怎么算？
