## 一、用户原话（逐字，不改写）

### 1. 地形编辑：连通性与地形 type 是两件事

> 「首先是地形编辑模式，道路/河流编辑的本质是连通性编辑，和hex地形type编辑根本不是同一个东西，**你就不愿意做个子选项吗**？GSimulator对于道路/河流编辑已有成熟方法」

### 2. 审批 UI：我没让你在右边做

> 「然后是决议，**谁让你在右边做一个审批界面了**？可以做一个右下角的简单通知栏，但是具体的审批，和**压根不知道在哪看的决策人查看**，应该**单独做一个新模式**」

### 3. 决策人模式的交互

> 「如果是国家决策人，那么**在地图上把对应国家区域显示出来**，于决策人模式下**选中这个区域就能在左边面板看这个国家决策人的信息**；单位也是，**选中有决策人的单位就看这个单位决策人的信息**；此外可以在**决策人信息查看界面的右边单独显示所有决策人列表，按类型分类排列**」

### 4. 时间线：推进 ≠ 每 tick 都生成决策

> 「还有一个大问题，时间线，默认并不是**每tick推进都要生成决策**，最好是，**推进一tick后，于决策人信息界面右边列表显示哪些决策人理论上建议决策**，**真正开始决策的按钮掌握在GM系统（用户操作优先、GM Agent其次）那里**」

### 5. GM Agent 界面

> 「还有，**GMAgent的显示界面呢**？应该在最底部那一栏**额外做一个按钮**，点一下就**全屏一个GM交互界面**，允许**看所有命令+GM Agent对话**」

### 6. 一阶段的现实取舍（★ 用户已给定方向）

> 「不过目前一阶段，更靠谱的是把**GMAgent的Tool打包成MCP**，由**外部Agent接入、担任GM**，这个**GMAgent界面只显示GM MCP的Tool使用**」

### 7. 本次指令

> 「作为阶段修复**开始进行调查和规划**」

## 四、控制器自陈（为什么会出现这些）

用户这轮指出的问题，**根因不是"功能没做"，而是"形态做错了/没被要求就做了"**：

1. **R1**：M8 把"地形"和"连通性"当成同一模式的两种命令 ⇒ **概念上没有区分"属性编辑"与"拓扑编辑"**。
2. **R3**：审批 UI **超出派单范围**——我把"审批装配（M5 T6 的**后端**能力）"顺手做成了**前端界面**，**用户没有要求**。
3. **R9/R11**：时间线被我实现成"**推进即决策**"的暗示（M7f 一 tick 一节点），而**决策是 GM 权限、不是 tick 的副作用**。
4. **R5~R8/R12**：**决策人/GM 这一整块从来没有 UI** ——SDSimos 做的是**能力**（模型/命令/工具/渠道），**界面完全缺席**，所以「压根不知道在哪看」。
5. ★ 更基本的：**这五轮我把"门禁绿"当成了"对了"**（见 `.superpowers/sdd/2026-09-20-sd-simos/progress.md` 与本次会话）；**判据守的是"代码行为"，守不住"产品形态"**——形态只能靠**你和界面**发现。

### R4 审批 + 决策人查看：**两个子页面**
> 「4、两个子页面吧」
⇒ **一个模式**（模式名 = **决策**）**下挂两个子页**：子页 A「决策人查看」/ 子页 B「审批」。★ 子页具体命名待定。

### R5 「用户优先、GM Agent 其次」：★ 用户反问澄清
> 「5，这里的Agent是GM Agent还是决策人Agent?决策人Agent不是异步的吗」
⇒ **指 GM Agent**；**决策人 Agent 是异步的、不参与"开始决策"的抢占**（它只负责异步出令）。
⇒ ★★ **三件事必须分开**（本阶段最关键模型）：

```
① 推进一 tick（世界前进，与"决策"无关）
② 服务端算出【本 tick 哪些决策人理论上有待决事项】   ← 现在不存在，必须新造
③ 列表显示（决策模式右栏）
④ 「开始决策」按钮在 GM 系统 ← 用户点=直接生效；GM Agent 点=过审批门链
⑤ 决策人 Agent 被发起后【异步】出令（经渠道提交）
⑥ 结果落 revision
```
**「建议」≠「开始决策」≠「决策人出令」**——三件事、三层权限。
