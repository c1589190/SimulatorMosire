## §2 我对这轮要求的理解

这轮不是调参数，而是把经济循环重新明确成下面这条主线：

```text
Social 出人口、劳动能力、基本消费需要
→ 家户按“纯库存财富”富→穷选择生产方式/位置
→ 生产主导者发布工资表
→ 家户按所选生产方式算需求
→ 需求 + 到期债务占用的库存先扣出来
→ 剩余库存按市场区参考价挂牌
→ 家户按富→穷购买
→ 购买不足的部分记货币债
→ 用实际库存复核生产方式；不够就停止该生产、转为无业，只保留基本消费
→ 劳动匹配/雇佣
→ 生产执行，产出和入库在同一生产结算环节完成
→ 下一 tick 统一处理到期债务，允许用货物抵扣
→ Social 再算出生/死亡
```

这里要特别确认的政治经济学口径：

- **富裕程度**只看家户纯库存价值，不扣债务；不把“有债的富人”排到穷人后面。
- **生产方式选择**是家户在可竞争的多种生产方式/位置中选择，不是把一张生产方式表硬填给所有家户。
- **生产主导者**对自己的生产组织有工资定义权；工资不是系统黑箱直接给定。
- **无业**也是一种生产方式：只保留基本消费，不额外加一份口粮储备。
- **生活储备**不再单独存在；基础口粮需求已经并进生产方式的生产消耗/需求。
- **市场价**保留当前“市场区参考价”体系，不做平均成交价挂牌。
- **债务本金**只以货币计算，不记实物债；不同市场区的货币按早先裁定的汇率折算。

## §3 当前代码与目标的主要差异（先记事实）

1. 当前生产、抽料、劳动匹配都在市场之前；目标要求市场先于实际生产。当前顺序见 `EconomySettlement.java:1634-1680`、`:1751-1752`、`:2183+`。
2. 当前生产匹配按 `HouseholdId` 稳定序，不是纯库存财富序；见 `LaborQueueSettlement.java:314-315`。
3. 当前市场购买排序用“资产 − 负债净值”，不是纯库存；见 `SettlementOrderBook.java`。
4. 当前没有“生产主导者自动生成工资表”的 tick 内实现；`ProductionWageBook.adjustedPostings` 没有生产 tick 调用者。
5. 当前买盘目标含 35 天生活储备（`MarketSettlement.householdLifeReserveOf`），目标要求删除这层额外生活储备。
6. 当前卖单可卖量扣的是 `productionCost + demandTarget`，不是“需求 + 本 tick 到期债务”。
7. 当前市场赊购直接记 `DebtUnit.Money`；但债务模型还支持 `DebtUnit.Commodity`，目标要求债务只按货币计算。
8. 当前债务偿还只在产业关账日，不是每 tick 统一处理；见 `EconomySettlement.java:2884`、`:3008`。
9. 当前产出在关账后进库存、再开市场；目标要求“生产结算和入库同一环节”，具体按生产方式的结算周期执行。

## §4 提议的 tick 设计（用用户的语言）

### 4.1 一级日序

```text
A. Social 出当 tick 的人口、劳动能力、基本消费需要
B. 经济载入家户；先处理上一 tick 留下的到期债务
C. 家户按纯库存财富富→穷，选择生产方式/位置
D. 生产主导者发布预计工资表
E. 家户按所选生产方式计算需求
F. 家户扣除“生产需求 + 本 tick 到期债务”后，挂牌剩余库存
G. 市场区按家户财富序购买
H. 市场买不到的部分记货币债
I. 按实际库存复核生产方式；不够则停止生产、转无业，只保留基本消费
J. 劳动匹配/雇佣
K. 生产执行；产出与入库同一生产结算环节
L. 下一 tick 统一处理到期债务（允许货物抵扣）
M. Social 根据经济结果处理出生/死亡
```

这里的“市场轮 5 tick 一结”建议明确成：

- 每天都有生产、消费、债务和服务；
- **市场只在 5 tick 的市场轮开市**；
- 市场轮当天，市场在生产之前；
- 非市场日不购买，只能用已有库存；
- 生产方式的结算周期仍然按生产方式自己：日结的在每个生产日入库，周期结的在周期末入库。

### 4.2 家户生产方式选择

不再“一张生产方式表把所有家户填进去”，而是：

1. 为每个家户生成**有资格的候选生产方式/位置**。
2. 每个候选行包含：
   - 生产方式与位置；
   - 是否组织者；
   - 预计产出与市场价格；
   - 预计生产资料投入；
   - 预计活劳动需求；
   - 预计净收益；
   - 需要的库存/资产条件。
3. 家户按**纯库存财富降序**依次选择：
   - 纯库存财富 = 货币余额 + 商品库存按当地市场区参考价折算；
   - 不含债务；
   - 不含生产资料份额（是否纳入需要确认）。
4. 每个家户只选一个**主生产方式**；其他生产方式不是被系统填满，而是留给其他家户竞争。
5. 生产主导者按自己的预期收益发布工资表；没有主导者组织起来的 mode 就不生产。
6. 所有可竞争 mode 都没选上，或所选 mode 的库存条件不满足 → 无业。
7. 无业不是“没有需求”：无业本身是一个生产方式，保留基本消费需求。

**待确认**：主生产方式选择按“绝对净收益”还是“每单位劳动净收益”排序？我建议用“扣除基本消费后的每单位劳动净收益”，因为它同时比较不同劳动强度的 mode。

### 4.3 工资表与劳动匹配

- 生产主导者在选择 mode 后，按自己的预期产出、投入成本、目标劳动量，发布：
  - 目标劳动量；
  - 单位劳动工资；
  - 工资币种；
  - 预计用工位置。
- 工资要真正算：`due = 工资率 × 实际劳动 + 进位余数`，按实际劳动结算。
- 工资调整沿用现有 U20 的方向：缺工加价、招满后缓慢降价；但触发点改为本 tick 的实际匹配。
- 劳动匹配发生在实际库存复核之后、生产执行之前：
  - 库存不够的 mode 已经取消，不再发工资；
  - 工人只在仍然成立的生产组织里选择；
  - 工资债仍按用户此前裁定：货币债、0‰ 欠薪利率（如未撤回）。
- **待确认**：如果工资工人在市场购买之前没有现金，是否允许用预期工资先赊购，还是只能靠已有库存/现金？我建议允许市场购买不足部分记货币债，下一 tick 统一还债。

### 4.4 需求

每个家户的需求统一由所选生产方式产生：

- **有业家户**：
  - 生产所需资料/原料（`demandParts` 保留）；
  - 该生产方式对应的基本口粮/基本消费；
  - 本 tick 到期债务（用于库存占用，不是消费）。
- **无业家户**：
  - 只有基本消费；
  - 不产生生产投入需求。
- **不再有额外的 35 天生活储备**。
- 需求是“必要”的：基础口粮属于生产方式的生产消耗；不是消费之外再叠一层生活储备。
- `demandParts` 作为生产所需保留；是否把其中一部分改成“生产方式需求表”的字段，需要确认代码命名，但语义上必须保留。

### 4.5 剩余库存与市场挂牌

```text
可挂牌剩余 =
    现有实物库存
  − 生产需求（有业）
  − 基本消费（所有家户）
  − 本 tick 到期债务占用
```

- 只有剩余部分挂牌；
- 挂牌价 = 当前市场区参考价；
- 不使用市场区平均成交价；
- 保留当前 `MarketTable` 的卖方 bid / 买方 ask / 成交参考价体系；
- 生产需求不再被当成“生活储备”，也不在消费之外再扣一次。

### 4.6 购买顺序与支付

- 市场区内的买家按**纯库存财富富→穷**排序；不扣债务。
- 购买时先用货币；
- 货币不足的部分直接记**对卖方的货币债**；
- 不在购买环节拿商品抵货款；
- 市场买不到的部分不伪造成交，进入未满足需求/缺口读数；
- 下一 tick 统一还债时，允许用货物抵扣货币债。

**待确认**：购买排序的“纯库存财富”是否只包括货币 + 商品库存，还是也包括可立即变现的生产资料？我建议只包括货币 + 商品库存，和生产方式选择的财富口径一致。

### 4.7 实际库存复核与生产方式停止

市场结束后，按实际库存复核每个已选生产方式：

- 生产资料/原料不足；
- 资产占用不成立；
- 劳动条件不成立；
- 或生产方式本身的条件不成立。

处理：

- **停止该生产方式的生产**；
- 该家户转为无业；
- 只保留无业基本消费；
- 已经为该生产方式准备的劳动/工资表按“未发生生产”处理，不支付虚假工资；
- 该 tick 不自动改选另一个 mode（按用户原话“直接停止...设为无业”）。

**待确认**：如果该家户是生产主导者，且市场不足导致 mode 停止，是否允许其劳动工人转投其他生产组织，还是全部随该 mode 一起转无业？我建议工人可以重新进入劳动匹配，因为他们本人没有失败；失败的是这个生产组织。

### 4.8 生产与入库

- 生产方式有自己的结算周期：
  - 日结 mode：每个生产日产出并入库；
  - 周期 mode：周期末产出并入库；
  - 两者都在**同一个生产结算环节**完成，不另设“生产完再单独入库”的步骤。
- 产出入库后，下一市场轮才卖出（如果本轮市场已经过去）。
- 生产产生的经验、进度、资产占用、工资义务仍按生产方式结算周期处理。

### 4.9 债务

目标口径：

- 债务本金只用货币单位，不用商品单位；
- 可以同时存在不同市场区的货币债；
- 跨市场区货币折算按早先裁定的汇率口径；
- 市场购买不足部分：对卖方的货币债；
- 下一 tick 统一还债：
  - 优先用货币；
  - 允许用货物抵扣；
  - 货物按当地市场区参考价估值，再按实际汇率折成债务币种；
  - 没有价格/汇率则不折、不静默当 0；
  - 还不上就留债，不因库存扣光而把额外债务塞进需求里。

**需要确认**：你说的“汇率见很早之前的裁定”，我理解是指“官方汇率 + 实际汇率/市场区平均兑换汇率”的那套；债务折算用**实际市场汇率**，还是用官方汇率？我建议用实际市场汇率，官方汇率只作为政府窗口报价。

## §8 第二轮裁定后的设计修订（待确认）

### 8.1 一级顺序改为 Social 先

新的日序：

```text
A. Social 先结算上一 tick 留下的人口事实：出生、死亡、年龄、劳动能力
B. 经济载入“活着的家户”
C. 经济处理上一 tick 已到期的债务

G. 市场区挂牌剩余库存；市场按富→穷购买
H. 市场购买不足 → 货币债
I. 实际库存复核；不足的生产位置停止，家户整体落入无业档
J. 劳动匹配/雇佣
K. 生产执行；产出与入库同一生产结算环节
L. 下一 tick 统一处理到期债务，允许货物抵扣
```

关键变化：

- Social 先于经济；
- 死掉的人不会在同 tick 进入市场；
- 经济结算使用 Social 结算后的家户；
- 本 tick 经济产生的缺口/死亡事实留到下一 tick 开头给 Social。

### 8.2 生产位置组合与贪心

家户不再只选一个“生产方式”，而是选一组“生产位置”：

```text
主生产位置 = 预期净收益最高且可行的位置
剩余劳动 = 家户劳动预算 − 主位置已用劳动
然后继续在剩余劳动里选下一个最有价值的位置
直到：
  - 劳动预算用完；
  - 没有可行位置；
  - 所有剩余位置都达不到基本生存/收益门槛。
```

需要新增/明确的语义：

- `ProductionPosition`：生产方式允许的一个具体位置（组织者、雇工、合作参与者等）；
- 每个位置有自己的劳动需求、资格条件、支付形态；
- 家户的 `laborMilli` 是组合预算，不是每个位置各拿一份；
- 选择是贪心的：每轮取“剩余劳动可承受、预期收益最高”的位置；
- 同一家户可以是多个位置的主体，但总劳动不超过预算。

### 8.3 工资：市场区位置工资锚，不是每个主导者自己算

第二轮裁定把工资从“生产主导者自己定价”改成“市场区按位置形成工资锚”：

- 工资锚的键 = `市场区 × 生产方式 × 位置`；
- 生产主导者只提出：这个位置要多少人/多少劳动；
- 市场区按该位置的劳动供给与需求，形成工资；
- 工资变化：
  - 初始可以很低，甚至 0；
  - 下一市场 tick 招不到人 → 逐步加价；
  - 有人来、招满了 → 逐步降价；
  - 降价到有人离开、规模不满 → 再加价；
  - 形成动态平衡。
- 生产主导者按市场工资估算自己的成本：
  - 预计收益 − 市场工资成本 − 其他投入；
  - 如果为负，就不选这个生产方式，改选其他生产方式或无业；
  - 因此主导者不需要自己计算工资表，只按市场位置工资做收益排序。

### 8.4 价格：市场区动态贪心

商品价格不再只是固定参考价，而是市场区按供需做动态贪心：

- 某一商品有求无供 → 价格逐步上涨；
- 价格上涨抬高该生产方式的预期收益，吸引更多家户选择该生产方式；
- 有供无求 → 价格逐步下降；
- 家户挂单使用市场区贪心计算出来的价格。

**待确认的实现口径**：

1. 贪心是在**一轮市场内反复试价直到供需平衡**，还是**每轮市场只调整一次、下一轮生效**？
2. 如果需求是必要的、且可以赊购，价格涨了需求也不会消失；这时“涨到有供无求”可能在固定供给下永远达不到。是否需要：
   - 设价格上限；
   - 供不应求时按数量配给；
   - 或允许价格跨多轮上涨，用生产周期慢慢增加供给？

### 8.5 债务：只按货币计，允许多币种

- 债务本金只用货币单位，不记实物本金；
- 可以存在不同市场区货币的债务；
- 跨市场区还债：
  1. 先走 FX，算市场汇率；
  2. 有汇率 → 产生兑换需求，用兑换后的货币还债；
  3. 没有汇率 → 先 FX、再按“对面市场区的货币—实物价格”用货物还债；
  4. 还不起 → 债务继续累积。
- 货物只是还债介质，不是债务本金单位。

### 8.6 生产与入库

- 日结生产方式：每天生产结算、当天入库；
- 周期生产方式：周期末生产结算、周期末入库；
- 生产结算和库存增加是同一个环节；
- 市场在生产之前；本 tick 生产出来的东西进入下一市场 tick。

## §10 第三轮裁定的具体解释

### 10.1 上一 tick 生存事实：单槽内存，不做逐 tick 历史

- 不做 `30tick/60tick` 的逐 tick 历史表；
- 在 app 内存中只保留**上一 tick 一份** `pendingFamineFacts`；
- tick t 开始由 Social 消费；tick t 经济结束后覆盖成 t 的缺口事实；
- 不落盘、不进 ChangeSet、不进 Codec；
- 推进多少 tick 只保留最近一份；进程重启后这份内存事实为空（Alpha 接受）。

### 10.2 外部注入需求与生产投入需求分开命名

- 当前 `HouseholdDemand` / `demandParts` 表示**外部注入需求**，不是生产投入；
- 外部注入需求继续保留给其他模块使用；
- 生产投入需求单独建表/类型，不混名；
- 建议命名：
  - 外部注入：`ExternalDemand` / `InjectedDemand`；
  - 外部注入的订单部分：`externalDemandParts`；
  - 生产投入：`ProductionInputDemand`；
  - 家户基本消费：`SubsistenceDemand`；
  - 统一的家户计划：`HouseholdProductionPlan`。

### 10.3 0 工资不是特殊拒绝条件

- 0 只是工资数值下界；
- 不在代码里写 `wage == 0 ⇒ 不接`；
- 家户对每个生产位置算“报酬 − 成本”的净收益；
- 受雇、小农、合作生产等都用同一套净收益判断；
- 赚钱才从事，不赚钱就不从事；
- 市场工资从 0 开始时，若算下来不赚钱，自然没人来，下一市场 tick 调高。

### 10.4 赊购只在“有货但买不起”时发生

- 市场有供给、有成交，但买方现金不足 → 未付部分记货币债；
- 市场没有供给 → 只是未满足需求，**不记债**；
- 不能因为下了买单就凭空产生债务；
- 价格调整采用跨市场 tick 逐步调整（方案 A），不在单轮内无限试价。

### 10.5 生产位置部分失败：失败部分转无业劳动

- 家户可以有多个生产位置；
- 每个位置独立检查库存/条件；
- 失败位置取消；
- 该位置对应的劳动投入转为 `UNEMPLOYED/IDLE` 劳动；
- 其他位置继续；
- 所有位置都失败 ⇒ 该家户全部劳动转无业；
- 本 tick 不自动用失败位置的劳动改选新位置（除非后续另行裁定）。

### 10.6 债务与 FX

- 债务本金只按货币；
- 实物租金/实物工资欠款在形成债务时按当时当地市场价折成货币债；
- 市场赊购的债务币种 = 卖方所在市场区货币；
- 多币种债务跨区还债：
  1. 先走 FX 得到市场汇率；
  2. 有汇率 → 产生兑换需求，用兑换后的货币还债；
  3. 没有汇率 → 先 FX，再按债权人所在市场区的商品价格，用货物折成债务币种还；
  4. 仍不足 → 余债继续挂着，累加。

### 11.1 命名

外部注入需求与生产投入需求分开命名：

- `ProductionPosition`：生产方式允许的一个具体位置；
- `LaborMarketQuote`：市场区 × 生产方式 × 生产位置的工资锚；
- `PendingFamineFacts`：上一 tick 留给下一 tick Social 的缺口/饥荒事实（单槽内存）。

### 11.2 单槽内存

- 只保留上一 tick 一份 `PendingFamineFacts`；
- 不做 30/60 tick 历史表；
- 同一 Shell 生命周期内跨 `AdvanceTime` 调用保留；
- 不落盘、不进 ChangeSet、不进 Codec；
- 进程重启后为空（Alpha 接受）。

### 11.3 家户计划与收益判断

- 家户对每个生产位置算：
  `位置净收益 = 该位置的预计收入 − 直接投入 − 该位置承担的工资成本`；
- 受雇位置：收入 = 工资 × 预计劳动；
- 小农/自营/主导者位置：收入 = 预计产品收入 − 投入 − 雇工工资；
- 只把净收益 > 0 的位置纳入贪心；
- 贪心排序建议：单位劳动净收益降序，劳动预算用完为止；
- 选完后，用家户全部选定位置的净收益合计与基本消费比较：
  - 合计不能覆盖基本消费 ⇒ 不生产，全部劳动转无业；
  - 部分位置失败 ⇒ 只把该位置对应的劳动转入无业，其他位置继续。
- 0 工资没有特殊 `if`；0 只是数值下界，是否接受由上述净收益判断决定。

### 11.4 价格和工资的跨 tick 调整

- 商品价格与位置工资都在**市场 tick**调整，下一次市场 tick 使用新值；
- 市场轮内不反复试价；
- 商品：`D > S` 涨价，`S > D` 降价，`D == S` 保持；
- 劳动：某位置劳动需求 > 供给 ⇒ 工资上调；供给 > 需求 ⇒ 下调；
- 工资为 0 时没人来是“净收益不划算”的结果，不是代码特判；
- 生产主导者只发布“需要哪些位置、需要多少劳动”，不自己定工资；
- 生产主导者按市场工资估成本，亏钱则改选其他位置或无业。

### 11.5 债务与 FX

- 债务本金只用货币；
- 市场赊购只在有成交、但买方现金不足时产生；
- 市场赊购债务币种 = 卖方所在市场区货币；
- 实物欠款转货币债；
- 跨币种还债先走 FX；
- 没有 FX 时按债权人所在市场区的商品价格用货物折成债务币种；
- 余债继续挂着，累加。

## §13 第四轮裁定后的进一步口径

### 13.1 基本消费按市场间隔

- 基本消费需求按“到下一个市场轮”的间隔准备；
- 当前市场轮为每 5 tick 一次，因此市场轮购买 5 tick 的基本消费；
- 这不是 35 天生活储备；
- 市场轮之间的每日消费从这 5 tick 的存量里扣；
- 市场轮之间没有新的市场购买，只有生产、消费、劳动和库存变化。

### 13.2 生产位置与债务重算跟着市场轮

- 生产位置重选只在市场轮发生；
- 债务重算、到期处理、工资锚调整、商品价格调整都在同一市场轮；
- 市场轮之间，家户保持上一轮确定的生产位置；
- 日结生产方式继续每日结算；周期生产方式继续按自己的周期推进；
- 市场轮之间不重新选位置，也不重新生成债务计划。

### 13.3 贪心按单位劳动净收益

- `positionNet = expectedIncome − directInputCost − wageCost`
- `positionYieldPerLabor = positionNet / laborMilli`
- 贪心按 `positionYieldPerLabor` 降序；
- 只有 `positionNet > 0` 的位置才进入候选；
- 选完位置后，用全部位置净收益之和与基本消费比较；
- 赚不回基本消费 ⇒ 不生产，劳动转无业。

### 13.4 价格不会无限高的前提

- 有需求、且存在能满足该需求的**生产方式**时，价格上升会提高该生产方式的预期收益，进而吸引家户选择该位置并增加供给；
- 生产周期和市场轮存在时滞，所以价格可能短期高位，但不应无限上涨；
- 如果“有需求但没有对应生产方式”，那是生产端配置/需求端错配，不是正常价格发现；
- 对这种错配必须具名记录：`demand-without-production-mode`，不能静默靠无限涨价“解决”。

### 13.5 由此带来的一个待处理问题

- 市场轮之间如果 Social 先结算导致家户劳动能力下降，上一轮确定的生产位置可能不再可行；
- 该 tick 不能重选位置（位置重选只在市场轮）；
- 需要明确：是“按剩余劳动缩规模”，还是“该位置停止、劳动转无业”？

### 15.2 Social 死亡导致劳动减少：受着

- 不额外保护；
- 家户劳动减少后，按上一轮确定的生产位置继续算；
- 能缩就缩，缩不了就停止；
- 结果由实际劳动/库存/生产规则承担。

### 15.3 高价 + 未满足需求是正常现象

- 不设价格上限；
- 生产端饱和或没有可组织生产时，允许高价和未满足需求并存；
- 测试出现此类现象不当作 bug，只记录具名原因。

### 15.4 土地：当前模型已有产权底子，但没有土地市场

当前代码已有：

- `AssetKind.LAND`；
- `OwnershipStake`（owner/operator/quantity/kind/location）；
- `AssetOccupancyGrant`（占用区间）；
- 地租/租佃关系 `ProductionRules`；
- 生产产能 `capacityPerUnit` 使用 LAND。

缺口不是“完全没有土地产权”，而是：

1. 没有土地买卖市场；
2. 没有按生产方式/位置表达的“土地需求”；
3. 没有地主/中农/雇农的初始土地分布规则；
4. 没有土地价格/地租与阶级流动的闭环。

### 15.5 土地应作为资产市场，不应直接混入普通商品市场

建议：

- `OwnershipStake(asset=LAND)` 仍是土地数量的唯一权威；
- 另建土地交易/租赁市场：
  - 买卖：转移 `OwnershipStake`；
  - 租赁：生成/变更 `AssetOccupancyGrant` + 租金关系；
  - 价格：按土地供需动态调整；
- 不把 LAND 同时塞进 `CommodityId` 库存，否则会与 `OwnershipStake` 数量双记。

### 15.6 初始阶级与土地需求

建议初始：

- 地主位置：拥有/占用大量土地；
- 中农：拥有少量土地，主要自耕；
- 佃农/雇农：无地或少地，只能提供劳动；
- 土地买卖/租赁市场允许后续改变这个分布。

用户原话里“同等劳动力下的大量土地需求”需要进一步确认是：

- 地主生产方式/位置的**土地需求系数**；
- 还是地主家户的初始土地**所有权配置**；
- 还是两者都要。

## §16 土地设计：待确认的推荐方案

### 16.1 现状不是“没有土地产权”，而是“没有土地市场”

当前已有：

- `AssetKind.LAND`；
- `OwnershipStake` 的 owner/operator/quantity/kind/location；
- `AssetOccupancyGrant`；
- 地租/租佃关系；
- `capacityPerUnit` 使用 LAND。

缺的是：

- 土地买卖市场；
- 土地租赁市场；
- 按阶级/生产位置的初始土地分布；
- 土地需求系数；
- 土地价格与地租的闭环。

### 16.2 推荐：土地是资产市场，不是普通商品库存

- `OwnershipStake(asset=LAND)` 继续是土地数量唯一权威；
- 土地买卖转移 `OwnershipStake` 的 owner；
- 土地租赁生成/变更 `AssetOccupancyGrant` 并结算租金；
- 不把 LAND 同时放进 `CommodityId` 库存，否则数量双记；
- 普通商品市场与土地资产市场可以共用市场 tick，但订单/结算类型分开。

### 16.3 初始阶级与土地需求（建议）

- 地主：初始拥有大量土地；对应生产位置的土地需求系数高；
- 中农：拥有少量土地，主要自耕；是否还有土地购买需求待确认；
- 佃农：无/少土地，靠租入土地，有土地使用需求但没有所有权需求；
- 雇农：无土地，只提供劳动；
- 土地买卖/租赁允许后续改变分布。

“同等劳动力下的大量土地需求”建议落成：

- 生产位置字段 `landRequiredPerLabor` 或 `landPerUnit`；
- 地主位置高，雇农位置 0；
- 中农/佃农按自耕/租佃分别配置。

### 16.4 土地价格与“不会无限高”的关系

普通商品可以通过生产增加供给；土地不能生产，供给固定。  
因此“有需求、有生产方式 ⇒ 价格不会无限高”对土地不自动成立：

- 如果土地所有者不卖，需求再高也没有成交；
- 如果允许高价 + 赊购，土地价格可能被需求推得很高；
- 需要另外规定土地价格形成：动态供需、租金资本化、或买家财富/信用上限；
- 土地是否计入“纯库存财富”也需要单独裁定。

## §18 土地按“普通商品流程”处理的设计约束

### 18.1 采用普通市场流程，但商品单位必须带地点

- 土地产权走和市场商品相同的订单、撮合、价格、结算流程；
- 但土地不是无地点的 fungible 库存；
- 商品单位建议定义为 `LandParcel` / `LandTitle`：
  - `LandParcelId`；
  - `location`；
  - `area/quantity`；
  - `quality`（可缺省）；
  - `title/ownership`。
- 不把土地同时塞进普通 `HouseholdGoods` 库存和 `OwnershipStake`；必须选一个权威记录。
- 推荐：`OwnershipStake(asset=LAND)` 作为产权权威，土地市场订单引用 `AssetShareId`/`LandTitleId`；成交只转移 owner，不搬动物理土地。

### 18.2 土地价格

- 土地供给固定，需求高时价格可很高；
- 不人为设低价上限；
- 但要有：
  - 买方支付能力/信用约束；
  - 抵押率/haircut；
  - 价格饱和算术；
  - 没有成交时的 `unmet` 记录。
- 若土地可抵押，必须定义抵押率；否则“土地涨价 → 抵押融资 → 再买地”可能形成无上限的信用扩张。

### 18.3 抵押

- 土地产权可以作为 `Pledge` 的标的；
- 债务违约/到期无法偿还时，债权人可按抵押规则取得土地产权；
- 抵押价值按市场区地价/预期地租估值；
- 需要明确：
  - 土地抵押率；
  - 违约后是强制转移所有权，还是先拍卖；
  - 抵押土地是否仍可生产/收租。

## §20 土地预占用与“无地主标签”方案分析

### 20.1 可行的核心

- 生产计划先占用土地，再进入市场；
- 市场 tick 新买的土地不用于本轮生产，下一市场轮才进入生产方式计算；
- 这样可以避免“边买地边改本轮生产规模”的循环依赖；
- 土地规模不同导致自耕/雇工选择不同，方向成立。

### 20.2 必须区分的三件事

1. **土地所有权**：谁拥有土地，可买卖、抵押、收租；
2. **土地使用权/占用**：本轮谁在地块上生产；
3. **生产位置与劳动雇佣**：自耕、雇工、组织者位置。

“按库存资产排队分配 hex 总土地”如果直接分配所有权，会绕开土地市场价格和既有产权；  
如果分配的是**可用土地使用权/租约**，则与私有产权和土地市场可以并存。

推荐：

- 所有权走土地市场（买卖、抵押、继承/初始配置）；
- 使用权走占用/租约分配（可由所有者自用、出租或市场租约）；
- 生产位置只读取本轮已经确定的土地使用权；
- 本轮新买土地不进入本轮生产；
- 下一市场轮重新计算生产方式和土地占用。

### 20.3 “取消地主标签”

建议改成连续变量：

- 土地数量/质量；
- 家庭劳动能力；
- 可雇佣劳动；
- 经验/技术；
- 资金/负债。

“富农—中农—贫农—雇农”只作为读数和阶层投影，不作为生产方式硬标签。  
一个家户有地就可以自耕或雇工；没有地就只能卖劳动或租地。

### 20.4 平衡是否成立

- 土地多、家庭劳动少 ⇒ 自耕受劳动约束，必须雇工或缩规模；
- 土地少、家庭劳动多 ⇒ 自耕足够，不必雇工；
- 有地无劳动 ⇒ 出租/雇工；
- 无地有劳动 ⇒ 受雇/租地；
- 经验提高劳动效率，改变自耕与雇工的比较；
- 价格影响产出收益，再影响雇工意愿。

但需要防止“所有人都能当地主”变成“所有人都不付代价抢地”：

- 无地家户要获得土地使用权，必须买地/租地；
- 本地没有可卖/可租土地，就只能当雇农；
- 不能因为“想当地主”就自动获得土地。

### 20.5 需要确认

1. 排队分配的是**土地所有权**，还是**土地使用权/租约**？推荐后者。
2. 初始土地是否全部已经分配到户，还是存在可分配的公共/无主土地？
3. 本 tick 买到的土地，是否只影响下一市场轮（本轮生产不使用）？用户已明确：是。
4. 土地买卖是否允许赊购/抵押融资？抵押率多少？
5. 土地计入“纯库存财富”吗？
6. 已出租/已占用的土地被出售时，买家是否必须承接现有租约到本轮/租期结束？

## §22 第八轮后的土地与库存口径

### 22.1 本轮生产只读上一轮落库结果

- 本轮的生产计划、土地占用、投入需求只看**上一轮已经落库的实际库存和土地产权/使用权**；
- 本轮市场 tick 新买到的货物/土地，不改变本轮生产计划；
- 新土地/新库存进入下一轮生产方式和需求计算。

### 22.2 标准预设

- 不走“所有家户同一初始资产 + 一堆 0 元公共土地”的极端预设；
- 标准预设：每个家户初始财产有差异，并拥有与财产规模相对应的土地；
- 土地产权/使用权初始就有差异；
- 公共土地可以作为测试预设，不作为标准世界默认。

### 22.3 土地计入纯库存财富

- 纯库存财富 = 钱 + 货物 + 土地按当前市场价折算；
- 不扣债务；
- 这个财富序用于生产位置选择、土地/市场排队。

### 22.4 土地信用与强制出售

- 允许用信用/抵押购买土地；
- 若下一轮无法偿还，债务人必须卖地；
- 强制出售走市场，不凭空没收；
- 出售所得先还债，剩余归债务人；不足部分继续挂债；
- 抵押土地出售时，必须处理现有租约/占用（见 22.5）。

### 22.5 分段计算

土地交易必须分段：

1. 产权转移；
2. 本轮已有租约/占用继续有效；
3. 下一轮生产计划再按新产权/新租约计算；
4. 强制出售同样不得打断本轮已锁定生产；
5. 买家承接现有租约到租期/本轮结束。

## §24 第九轮后的最小实现口径

### 24.1 本轮只读上一轮落库

- 本轮生产计划、投入、土地占用只读上一轮已落库的实际库存和土地产权/使用权；
- 本轮市场买卖的东西只进入下一轮计划；
- 土地买卖不改变本轮已经锁定的生产计划；但如果卖家把当前生产依赖的土地卖掉，生产中断、土地荒置是合法结果。

### 24.2 土地是生产方式模块的“限量特殊商品”

- 不考虑把它做成通用商品接口；
- 土地是 `AssetKind.LAND` / 生产方式模块下的限量特殊商品；
- 有地点、面积/数量、质量、所有者、经营者；
- 可买卖、抵押、强制出售；
- 不进入普通家户货物库存；
- 当前实现只要求满足生产方式对土地的需求和土地市场流转。

### 24.3 跨 hex 土地

- 市场区内不同 hex 的家户可以购买其他 hex 的土地；
- 土地本身没有运费；
- 但耕种其他 hex 的土地必须雇佣该土地所在 hex 的雇农；
- 土地所有者不能用自家劳动力跨 hex 耕种；
- 这会形成本地劳动市场与外地地主的关系。

### 24.4 融资与强制出售

- 不设融资上限；
- 允许用土地抵押/信用购买土地；
- 下一轮无法偿还 ⇒ 强制出售土地；
- 出售所得先还债，剩余归债务人，不足继续挂债；
- 需要处理：没有买家、土地价格不够、已有生产占用三种边界。

### 24.5 当前仍需决定的边界

1. 卖家卖出当前生产依赖的土地时，是立即中断本轮生产、土地荒置到下一轮，还是只影响下一轮？
2. 跨 hex 土地是否允许所有者亲自迁徙过去耕种，还是严格必须雇当地雇农？
3. 强制出售时没有买家，土地怎么处理？留债、降价、还是继续抵押？
4. 土地抵押/信用购买是否也允许“无首付、无上限”，还是至少有合同期限/到期日？
5. 土地计入纯库存财富后，其他生产资料（工具、作坊）是否仍不计入？
6. 已有租约/占用被出售时，是继续到本轮结束，还是可以立即中断？

## §25 最小自洽版：土地、库存、跨 hex 与融资

### 25.1 固定点

- 本轮生产只读上一轮落库的库存/土地/租约；
- 土地是生产方式模块的限量特殊商品，不走普通货物库存接口；
- 土地有地点、面积/质量、所有者、经营者；
- 土地所有权可在市场区内跨 hex 买卖，无运费；
- 跨 hex 耕种必须雇佣土地所在 hex 的雇农，所有者不能用自家劳动跨 hex 耕种；
- 本轮新买土地不进入本轮生产，下一轮才进入；
- 纯库存财富包含土地市值，不扣债务；
- 不设土地融资上限；还不上则下一市场轮强制出售；
- 不保留硬编码“地主/中农/贫农”生产方式标签；用土地、劳动、资金、经验连续变量表达。

### 25.2 建议的销售/使用分段

1. 市场轮开始：锁定本轮生产计划（使用上一轮土地/库存）；
2. 土地市场：所有权可以交易；本轮新买土地不进入本轮生产；
3. 若卖家卖掉自己本轮正在使用的土地：本轮该生产中断，土地荒置到下一轮（按用户口径，允许）；
4. 若土地存在有效租约：买主是否立即取得使用权需要单独确认；建议产权转移不自动打断有效租约，但卖家自用地可以中断；
5. 下一市场轮：新产权/新租约进入生产计划和土地排队。

### 25.3 强制出售

- 到期还不上 → 下一市场轮挂强制出售；
- 出售所得先还债，剩余归债务人，不足继续挂债；
- 没有买家 → 不伪造成交；债务继续，下一轮再卖；
- 强制出售不得制造本轮之前不存在的土地，只能转移已存在的地块。

### 25.4 仍需用户确认的最后边界

1. 有效租约在土地出售后是否继续到本轮/租期结束？
2. 强制出售无买家时，是否允许降低挂牌价直到成交，还是继续挂着？
3. 土地初始价格/估值从哪里来：测试世界数据、地租资本化、还是市场初始牌价？
4. 纯库存财富是否只加土地，不加工具/作坊等其他生产资料？

## §27 第十轮后的顺序与两阶段生产编排

### 27.1 市场 tick 最前面：清算负债、收回/清理租约

- 市场 tick 开头第一步：债务到期/清算；
- 清算时可以收回/解除土地租约与占用；
- 因此进入土地市场时，待售土地应当是“清掉旧租约/占用”的地；
- 土地出售一旦成立，旧占用不再继承；这是次序结果，不是额外规则。

### 27.2 两阶段生产编排

第一阶段：预期编排

- 用上一轮已经落库的实际库存、土地、租约；
- 家户按财富顺序选择生产方式/位置；
- 算出预期需求、预期土地需求、预期买盘/卖盘；
- 进入市场。

第二阶段：实际编排

- 市场 tick 结束后，家户实际库存/可动用投入可能不同于预期；
- 再做一次“生产参与重排”；
- 只根据实际可用库存、实际土地、实际劳动重新确认位置；
- 所有约束都要到位；
- 失败位置对应劳动转无业；
- 这次重排不再产生新的市场买卖。

### 27.3 强制出售的口径

- 不设“系统必须找到买家”的强制出售；
- 债务人把质押土地挂牌出售；
- 有买家 → 成交、还款；
- 没有买家 → 不成交、债务继续，下一市场轮再挂；
- 不凭空转移土地，也不伪造买家。

### 27.4 初始土地价格

- 初始地价可以为 0；
- 0 是合法价格，不是“没有价格”；
- 经济模块必须区分“未定价”和“定价为 0”；
- 0 地价土地可以自由转让；抵押价值为 0；不能凭空抵押出钱。

### 27.5 本轮范围

- 先做农村：土地、农业、雇农、地租、土地市场、债务/抵押；
- 工坊/手工业等工坊经济后面重新加入；
- 本阶段不改工坊生产语义。

### 27.6 仍需确认

1. 第二阶段实际库存是否包括本轮市场买到的货物？我建议：货物包括；土地不包括（土地购买下一轮才进入生产）。
2. 租约是否是“市场轮级”的，下一市场轮重新清理/重排？这会影响长周期生产是否会被打断。
3. 卖地后原经营者本轮是否立即停止、土地荒置到下一轮？按 B 应如此。

- 不再产生新的市场买卖；

  2. 穷债权人拿不到时，债务是否继续挂；
  3. 债权人全部死亡时，债权消灭、土地是否留债务人。
- 在这三条按最保守语义处理（债务继续、无买家不成交、债权人全灭债权消灭且土地留债务人）时，模型自洽。
- 不再引入抵押、担保、特定资产优先受偿等未授权机制。

```text
首先，为什么这块地会被挂到市场上，它应该在最开始的还债环节就被抵走了
```

## §43 纠正：土地在还债环节直接抵债，不挂市场

- 市场轮最前面的还债环节，直接处理债务人的可用资产；
- 可用于还债的资产包括：货币、库存、土地；
- 土地不需要先挂到土地市场再卖；
- 债权人按还债顺序直接取得土地抵债；
- 这不是抵押/担保，而是普通债务的资产清偿；
- 土地市场只处理没有被债务抵走的土地。

### 43.1 还债环节中的土地

```text
债务人到期债务
→ 可用资产：货币/库存/土地
→ 按债权人财富顺序受偿
→ 轮到某债权人时，直接以土地抵债
→ 土地价值 > 债务：整块抵走，不找零
→ 土地价值 < 债务：土地抵走，余债继续
```

### 43.2 待确认

- 土地按什么价格估值：当前市场区地价、最近成交价、还是世界数据价格；
- 多个债权人时，前顺位把土地抵走，后顺位只能拿剩余资产/余债；
- 债权人全部死亡：债权消灭，土地留债务人。

```text
当前市场区的土地价格啊
```

## §45 最终土地估值

- 土地抵债/计入纯库存财富/土地市场，统一使用**当前市场区土地价格**；
- 土地价格 0 是合法值；
- 债务清算时：
  - 土地价值 > 债务：整块抵走，不找零；
  - 土地价值 < 债务：土地抵走，余债继续；
  - 多个债权人按债权人财富顺序受偿；
  - 债权人全部死亡：债权消灭，土地留债务人。
- 不再使用抵押/担保/特定资产优先受偿机制。
