## §1 基础口径（v2：只用仍有效的裁定，不把作废公式列回待裁定）

### 1.1 已定（设计前提）

| # | 口径 | 来源/效力 |
|---|---|---|
| U13/U14 | 合作生产：一个生产方式/实例可由多家户分阶层角色参与；**同一生产方式各阶层积累的生产经验算同一个（同经验条）**；**每角色获得的经验量可配置** | 用户原话 |
| U15（含更正） | **直接产品分配**：地主的产品份额不以下地劳动为条件；**"按实际劳动权重 / 标准劳动权重"两种旧解释不再作为设计依据**。生产方式必须定义**支付物**（佃农制分粮；雇农制加"雇农"档并把工资义务计入地主）与角色/份额；工资以当地市场区货币计，货币不足按顺序用库存替代；**地主是报价方**、跟随当地市场。★ 表述更正：不是"组织者按雇农实际投入获得货币结算分成"，而是"**地主承担按实际雇工劳动计的工资义务**"（工资是地主的支出，不是地主的收入） | 用户原话 + 更正 |
| U16 | 算定劳动价格后**直接计薪/支付**；库存不足直接成债；**不另设土地生产资料**；用于再生产的资料视为**权益**，不算可变卖活动库存 | 用户原话 |
| U17 | **工资费用前置进入本户候选收益**：选业前按候选生产方式得到本轮可招到劳动的价格，计入预估费用再比较 | 用户原话 |
| U18 | 地主是**出价方**，可报零/很低；无产/流民须在自己可行方式中选择，**不以收支平衡/维生为必然可达**；不得隐含正工资或不亏本底线 | 用户原话 |
| U19 | 家户**允许不从业**（闲置是明确候选）；口粮→劳动能力沿用 Social；报价/选择/支付按 tick 推进，不要求单 tick 均衡 | 用户原话 |
| U20 | **缺工时加价快且可累加加速；招到人后降价缓慢、幅度渐增**（参数由工程给可配置默认、待仿真标定） | 用户原话 |
| U21 | 欠薪记录**不影响**下一 tick 择业；**禁止预付**；付款顺序 = 对应货币 → 可支付活动库存**按数量从多到少**抵付 → 仍不足成债；再生产权益/已投入资料不入候选 | 用户原话（最新） |
| D-033 | 文化=家户独有记录+宗教归属；每 hex×宗教地方教区（收奉献家户）；奉献=额外需求；税仍强制；择优信奉经人口流动。具体奉献公式/周期/优先级未定；**culture 保持占位** | 用户原话 |
| U6/U10/§15 | 主业/副业不设专门机制；冲突旧实现直接删（不兼容）；解锁永久；提交/同步需显式授权 | 用户原话 |

### 1.2 仍待工程设计的（不找用户选类名/账本）

- **资格/权益细节**：由生产方式条件选择"哪个位置/哪些实际操作人员"需满足资格；组织经营者从**实际参与名册**解析主体；某些位置要求资格 ≠ 全体参与者都要会。具体字段/解析算法在 §16 设计书里定。
- **资产占用**：在**现有权益/占用事实**里表达作用域、实际使用量、占用时段（可评估扩展 `OwnershipStake`）；**不得**恢复独立土地账/土地活动库存/第二份可写权威；统一预算不重复占用的 I8 仍要实现；R2 在 Phase A 关闭。
- **工资机制**：按 U19–U21 的"逐 tick 主动报价 + 家户可闲置 + 直接结算"设计；**不采用已撤回的 ΔB×k 定价公式**；两次试算/边际收益只可作为"是否值得加价"的辅助估计，不是统一出价公式，也不是劳动户自动分成。
- **经验增长表达式**：以实际参与劳动为输入的可配置表达式（先取实际贡献、可归一化、再乘角色系数）。默认建议按参与强度归一化；唯一可观察待定玩法见 §5。
- **生产定义形状/升级链**：先冻结共享定义形状，再动实现（见 §4 顺序）。

## §3 目标写法（模块级，v2 口径）

| 模块 | 写法 |
|---|---|
| `simos-production` | 唯一技术定义面：生产方式 = I/O + 升级链（技术=可选升级方案）+ **角色/位置** + **角色产品份额**（含角色池与角色内拆分配置；**直接产品份额，不以劳动为条件**）+ **经验规则**（同经验条、每角色增长系数/表达式可配置）+ **资格条件（按位置）** + **支付物/抵物条款**。实例 = 方案引用 + 地点 + 进度 + 实际投入/劳动/经验台账；**一次物理生产只算一份总产出**；分配/付款/账户不归本模块。 |
| `simos-economy` | 合作候选形成（能凑齐资源与角色）→ 家户比较**本户预计所得减本户负担**（含量化工资义务）→ 统一分配劳动/资产/原料 → production 执行 → 角色产品份额 + 工资结算（直付/抵物/成债）→ 账户经原所有者变更集。新建：参与名册（household↔instance↔role↔commitment）、雇主报价状态与 U20 调价、工资费用前置、资产实际占用与占用期、闲置选项、迁移按本户所得。 |
| `simos-app` | 只做编排/事实桥接：日循环次序（真实库存/劳动能力/报价 → 候选估算/选业 → 统一分配/生产 → 给付与生活结算 → Social 反馈与下一 tick 报价）；**不在组合根实现分配/报价公式**。 |
| `simos-social`/actor | 营养→劳动能力、人口/迁移既有；账户在 actor 侧落账（本计划不改）。 |
| `simos-culture` | 保持占位；D-033 另立计划。 |
