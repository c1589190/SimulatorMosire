## 1. 运行嵌入与交付顺序

| 阶段 | 输入 / 输出 | 顺序、身份、失败与验证影响 |
|---|---|---|
| 生产责任区 | 目标设计、现有状态 → 国家/领土/GOV 原子工具、完整编制原子工具、读视图与 PNG、网页入口 | 单个 dsh deepseek-flash 写入者；先领域再宿主装配；只编译，不写/跑测试，不提交 |
| 统一测试责任区 | 全部生产代码交回 → 正负用例、精确工具表与资源门禁、关键变异自证 | 独立测试 Owner；真实 Core 批回滚和 Social 人口读回；门禁通过前不能宣布完成 |
| 真实演示与验收 | 新 jar + 原地图的隔离副本 → MCP 图片、浏览器提交、真实世界移动和重启证据 | 原地图存档保持；虚构样例不冒称真实四国部队；多 tick 推进走外部真实世界，不放 JUnit |
| 关账 | 门禁、运行证据与 diff → 报告和当前状态 | 核实边界/统计/原始日志；无本次明确授权不再次 commit/push |

## 2. 责任边界

- gov：国家、领土计划、GOV 创建编排、国家视图与显示；map 只拥有几何。
- army：编制计划、军队身份、组织图；unit 继续拥有编制与移动，social 继续拥有人员。
- app：固定领域工具桥、统一写入与节点刷新、工具及资产装配；没有第二份领域计划。
- 生产 Agent 不处理测试，测试 Agent 不修改生产；发现生产问题交回重开唯一生产写入者。
